2.3  Rank-Nullity Theorem

2.3.1. Nullity and Rank

Definition 2.3.1 (Nullity)

Let f:V→W be a linear transformation. The nullity of f is defined by nullity(f):=dim⁡(ker(f)).

Definition 2.3.2 (Rank)

Let f:V→W be a linear transformation. The rank of f is defined by rank(f):=dim⁡(im(f)).

Example

Recall that for D:R[x]≤3→R[x]≤2 defined by D(f(x))=f′(x), we have ker(D)=R and im(D)=R[x]≤2. Compute the nullity and rank of D.

Solution. nullity(D):=dimR⁡(ker(D))=dimR⁡(R)=1.

rank(D):=dimR⁡(im(D))=dimR⁡(R[x]≤2)=3.

Remark. For other examples of nullity and rank, review the examples in the last section, which we have it covered.

2.3.2. The Theorem

Theorem 2.3.1 (Rank-Nullity Theorem)

Let V be a finite dimensional vector space and f:V→W be a linear transformation. Then we have nullity(f)+rank(f)=dim⁡(V).

Proof. Let S={v1,v2,…,vn} be a basis of ker(f), having nullity(f)=dim⁡(kerf)=n. Since ker(f)⊆V, by the Basis Extension Theorem (Theorem 1.6.5), we can extend S to S′={v1,…,vn,s1,…,sk}, a basis of V, having dim⁡(V)=n+k.

Claim. S″={f(s1),f(s2),…,f(sk)} is a basis of im(f).

Proof. We verify two properties.

Spanning. Let w∈im(f), we have w=f(v) for some v∈V by definition. As S′ is a basis of V, we can write v=∑i=1nαivi+∑i=1kβisi. Then we apply f to both sides: w=f(v)=f(∑αivi+∑βisi)=∑αif(vi)+∑βif(si)=∑βif(si), where the last equality holds since vi∈ker(f). Since w can be expressed by f(si)’s, therefore S″ spans im(f).

Linear independence. Suppose that α1f(s1)+⋯+αkf(sk)=0. By linearity of f, it becomes f(α1s1+⋯+αksk)=0. Therefore we have α1s1+⋯+αksk∈ker(f). Moreover, as S is a basis of ker(f), we know that ∑αisi=∑βivi for some βi∈F. Reordering gives ∑αisi−∑βivi=0. As S′ is linearly independent, this forces all αi’s and βi’s to be 0. This completes the proof of the claim.

Hence, we have rank(f)=dim⁡(im(f))=k=(n+k)−n=dim⁡(V)−nullity(f).

For the map fA:R4→R3, fA(v)=Av, the rank and nullity can be computed exactly with SymPy. In the online version the code can be edited and run; for any matrix, the sum is the number of columns, dim⁡(R4)=4.

from sympy import Matrix

A = Matrix([
    [1, 2, 3, 4],
    [2, 4, 6, 8],
    [1, 0, 1, 0],
])
rank = A.rank()                  # dim(im f_A)
nullity = len(A.nullspace())     # dim(ker f_A): size of a basis of the kernel
print("rank =", rank, " nullity =", nullity, " columns =", A.cols)
rank + nullity == A.cols

2.1  Linear Transformations

In Chapter 1, we studied vector spaces as static objects—sets equipped with addition and scalar multiplication. Now we turn to the study of structure-preserving maps between vector spaces. Just as group theory studies homomorphisms and topology studies continuous functions, linear algebra studies linear transformations.

A linear transformation is a function that “respects” the vector space structure: it preserves addition and scalar multiplication. This simple requirement has profound consequences. Linear transformations are the morphisms in the category of vector spaces, and understanding them is central to all of linear algebra.

2.1.1. Definition and Basic Properties

Definition 2.1.1 (Linear Transformation)

Let V,W be vector spaces over F. A function T:V→W is called a linear transformation (or linear map), if

  • (LT1) T(v1+v2)=T(v1)+T(v2), for all v1,v2∈V;
  • (LT2) T(λv)=λT(v), for all λ∈F and v∈V.

2.1.2. Examples of Linear Transformations

We now present a rich collection of examples. For each, we determine whether the given function is a linear transformation by verifying the two axioms (LT1) and (LT2).

Geometric Transformations

Example (Projection onto a Coordinate Axis)

Determine whether T:R2→R2 defined by T(a1,a2)=(a1,0) is a linear transformation.

Solution. Let v=(a1,a2) and w=(b1,b2) be vectors in R2, and let λ∈R.

  • Additivity: T(v+w)=T(a1+b1,a2+b2)=(a1+b1,0)=(a1,0)+(b1,0)=T(v)+T(w).
  • Homogeneity: T(λv)=T(λa1,λa2)=(λa1,0)=λ(a1,0)=λT(v).

Thus T is a linear transformation.

Example (Rotation in the Plane)

Determine whether rotation by angle θ (counterclockwise) in the plane is a linear transformation. That is, let Tθ:R2→R2 be the rotation map.

Solution. Write (a1,a2) in polar coordinates: a1=rcos⁡ϕ and a2=rsin⁡ϕ. Then: Tθ(a1,a2)=(rcos⁡(θ+ϕ),rsin⁡(θ+ϕ))=(rcos⁡θcos⁡ϕ−rsin⁡θsin⁡ϕ,rsin⁡θcos⁡ϕ+rcos⁡θsin⁡ϕ)=cos⁡θ(rcos⁡ϕ,rsin⁡ϕ)+sin⁡θ(−rsin⁡ϕ,rcos⁡ϕ)=cos⁡θ(a1,a2)+sin⁡θ(−a2,a1).

Thus Tθ(a1,a2)=(a1cos⁡θ−a2sin⁡θ,a1sin⁡θ+a2cos⁡θ).

Linearity follows from this explicit formula: for v,w∈R2 and λ∈R, Tθ(v+w)=cos⁡θ(v+w)+sin⁡θ⋅J(v+w)=Tθ(v)+Tθ(w),Tθ(λv)=cos⁡θ(λv)+sin⁡θ⋅J(λv)=λTθ(v), where J(a1,a2)=(−a2,a1) is itself linear.

Matrix-Induced Transformations

Example (Left Multiplication by a Matrix)

Let A∈Mm×n(F) be an m×n matrix. Determine whether fA:Fn→Fm defined by fA(v)=Av (where v is viewed as a column vector) is a linear transformation.

Solution. For v,w∈Fn and λ∈F:

  • Additivity: fA(v+w)=A(v+w)=Av+Aw=fA(v)+fA(w).
  • Homogeneity: fA(λv)=A(λv)=λ(Av)=λfA(v).

These follow from the distributive and scalar properties of matrix multiplication (Theorem 0.7.2).

For F=R and m=n=2, the map fA sends the unit square to the parallelogram spanned by Ae1 and Ae2, the columns of A.

The unit square (dashed) and its image under A=[2101].

Drag the tips of the two arrows to change A.

Example (A Specific Matrix Transformation)

Determine whether T:F3→F2 defined by T(a1,a2,a3)=(2a1+a3,a2−a1) is a linear transformation.

Solution. This is the matrix transformation induced by A=[201−110], since [201−110][a1a2a3]=[2a1+a3a2−a1]. By the previous example, T is linear.

Example (Trace)

Determine whether the trace function tr:Mn(F)→F defined by tr(A)=∑i=1naii is a linear transformation.

Solution. For matrices A,B∈Mn(F) and λ∈F:

  • Additivity: tr(A+B)=∑i=1n(aii+bii)=∑i=1naii+∑i=1nbii=tr(A)+tr(B).
  • Homogeneity: tr(λA)=∑i=1nλaii=λ∑i=1naii=λtr(A).

Thus trace is a linear transformation from the vector space of matrices to the scalar field.

Polynomial and Function Space Transformations

Example (Multiplication by x)

Determine whether T:F[x]→F[x] defined by T(f(x))=x⋅f(x) is a linear transformation.

Solution. For polynomials f,g∈F[x] and λ∈F:

  • Additivity: T(f+g)=x(f+g)=xf+xg=T(f)+T(g).
  • Homogeneity: T(λf)=x(λf)=λ(xf)=λT(f).

Thus multiplication by x is a linear transformation.

Example (Differentiation)

Determine whether D:R[x]→R[x] defined by D(f(x))=f′(x) (the derivative) is a linear transformation.

Solution. For polynomials f,g∈R[x] and λ∈R:

  • Additivity: D(f+g)=(f+g)′=f′+g′=D(f)+D(g).
  • Homogeneity: D(λf)=(λf)′=λf′=λD(f).

These are the standard sum rule and constant multiple rule from calculus.

Remark. More precisely, D:R[x]≤n→R[x]≤n−1 maps polynomials of degree at most n to polynomials of degree at most n−1.

Example (Integration)

Determine whether T:R[x]→R[x] defined by T(f(x))=∫0xf(t)dt is a linear transformation.

Solution. For polynomials f,g∈R[x] and λ∈R:

  • Additivity: T(f+g)=∫0x(f(t)+g(t))dt=∫0xf(t)dt+∫0xg(t)dt=T(f)+T(g).
  • Homogeneity: T(λf)=∫0xλf(t)dt=λ∫0xf(t)dt=λT(f).

These follow from the linearity of the integral.

Example (Shift Operator)

Fix θ∈R. Determine whether the shift operator Sθ:C(R)→C(R) defined by Sθ(f)(x)=f(x−θ) is a linear transformation. (This operator translates the graph of f by θ units to the right.)

Solution. For f,g∈C(R) and λ∈R:

  • Additivity: Sθ(f+g)(x)=(f+g)(x−θ)=f(x−θ)+g(x−θ)=Sθ(f)(x)+Sθ(g)(x).
  • Homogeneity: Sθ(λf)(x)=(λf)(x−θ)=λf(x−θ)=λSθ(f)(x).

Thus the shift operator is linear.

Example (Composition Operator)

Fix a continuous function g:R→R. Determine whether the composition operator Cg:C(R)→C(R) defined by Cg(f)=f∘g, i.e., Cg(f)(x)=f(g(x)), is a linear transformation.

Solution. For f,h∈C(R) and λ∈R:

  • Additivity: Cg(f+h)(x)=(f+h)(g(x))=f(g(x))+h(g(x))=Cg(f)(x)+Cg(h)(x).
  • Homogeneity: Cg(λf)(x)=(λf)(g(x))=λf(g(x))=λCg(f)(x).

The shift operator is the special case where g(x)=x−θ.

Identity and Inclusion Maps

Example (Identity Map)

Let V be a vector space. Determine whether the identity map idV:V→V defined by idV(v)=v is a linear transformation.

Solution. For v,w∈V and λ∈F:

  • Additivity: idV(v+w)=v+w=idV(v)+idV(w).
  • Homogeneity: idV(λv)=λv=λidV(v).

The identity map is trivially linear.

Example (Inclusion Map)

Let W⊆V be a subspace. Determine whether the inclusion map ι:W↪V defined by ι(w)=w is a linear transformation.

Solution. The inclusion map is simply the identity map restricted to W, viewed as a map into V. The verification is identical to the identity map.

Example (Zero Map)

For any vector spaces V and W, determine whether the zero map 0:V→W defined by 0(v)=0W for all v∈V is a linear transformation.

Solution. For v1,v2∈V and λ∈F:

  • Additivity: 0(v1+v2)=0W=0W+0W=0(v1)+0(v2).
  • Homogeneity: 0(λv1)=0W=λ0W=λ⋅0(v1).

The zero map is linear.

Field-Dependent Examples

Example (Complex Conjugation)

Determine whether complex conjugation T:C→C defined by T(z)=z―, where a+bi―=a−bi, is a linear transformation.

Solution. As a map of C-vector spaces: T is not linear over C.

Consider z=1 and α=i. Then: T(αz)=T(i)=−i,butαT(z)=i⋅1―=i. Since T(i⋅1)=−i≠i=i⋅T(1), the homogeneity condition fails.

As a map of R-vector spaces: T is linear over R.

For z=a+bi and w=c+di with a,b,c,d∈R, and λ∈R:

  • Additivity: T(z+w)=(a+c)+(b+d)i―=(a+c)−(b+d)i=(a−bi)+(c−di)=T(z)+T(w).
  • Homogeneity: T(λz)=λa+λbi―=λa−λbi=λ(a−bi)=λT(z).

This example illustrates that linearity depends on the choice of scalar field.

2.1.3. Non-Examples of Linear Transformations

It is equally important to recognize functions that are not linear transformations. We verify non-linearity by finding a counterexample to either (LT1) or (LT2).

Example (Squaring)

Determine whether T:F2→F2 defined by T(a1,a2)=(a12,0) is a linear transformation.

Solution. We show that T fails additivity. Consider v=(1,0): T(v)+T(v)=(1,0)+(1,0)=(2,0), but T(v+v)=T(2,0)=(4,0). Since (2,0)≠(4,0), additivity fails and T is not linear.

Alternatively, homogeneity fails: T(2v)=T(2,0)=(4,0)≠2⋅(1,0)=(2,0)=2T(v).

Example (Norm)

Determine whether T:Rn→R defined by T(v)=∥v∥ (the Euclidean norm) is a linear transformation.

Solution. Homogeneity fails for negative scalars. Consider v=(1,0,…,0) and λ=−1: T(λv)=T(−1,0,…,0)=∥(−1,0,…,0)∥=1, but λT(v)=(−1)⋅∥(1,0,…,0)∥=−1. Since 1≠−1, homogeneity fails and T is not a linear transformation.

(The norm does satisfy ∥cv∥=|c|∥v∥, but this is not the same as c∥v∥ when c<0.)

2.1.4. Basic Theorems

Theorem 2.1.1 (Zero Maps to Zero)

Let T:V→W be a linear transformation. Then T(0V)=0W.

Proof. Using additivity with v=0V: T(0V)=T(0V+0V)=T(0V)+T(0V). Adding −T(0V) to both sides gives 0W=T(0V).

Remark. This theorem provides a quick test for non-linearity: if T(0)≠0, then T is not linear.

Example (Constant Function)

Determine whether T:R→R defined by T(x)=5 for all x∈R is a linear transformation.

Solution. We use Theorem 2.1.1: any linear transformation must map zero to zero.

Here, T(0)=5≠0.

Therefore, T is not a linear transformation.

Example (Translation)

Determine whether T:R2→R2 defined by T(v)=v+c for some fixed nonzero c∈R2 is a linear transformation.

Solution. Using Theorem 2.1.1: T(0)=0+c=c≠0.

Therefore, translation by a nonzero vector is not linear.

Maps of the form v↦Av+c are called affine transformations. They are linear if and only if c=0.

Theorem 2.1.2 (Linear Maps Preserve Negation)

Let T:V→W be a linear transformation. Then T(−v)=−T(v) for all v∈V.

Proof. Using homogeneity with λ=−1: T(−v)=T((−1)v)=(−1)T(v)=−T(v).

Theorem 2.1.3 (Equivalent Characterization of Linearity)

Let V,W be vector spaces over F and T:V→W be a function. Then T is a linear transformation if and only if T(αv1+βv2)=αT(v1)+βT(v2) for all α,β∈F and v1,v2∈V.

Proof. (⇒) Suppose T is linear. Then for any α,β∈F and v1,v2∈V: T(αv1+βv2)=T(αv1)+T(βv2)(by LT1)=αT(v1)+βT(v2)(by LT2)

(⇐) Suppose T(αv1+βv2)=αT(v1)+βT(v2) for all α,β∈F and v1,v2∈V.

  • Additivity (LT1): Setting α=β=1, we get T(v1+v2)=T(v1)+T(v2).
  • Homogeneity (LT2): Setting β=0, we get T(αv1+0)=αT(v1)+0⋅T(v2), i.e., T(αv1)=αT(v1).

Thus T satisfies both (LT1) and (LT2), so T is linear.

Theorem 2.1.4 (Linear Maps Preserve Linear Combinations)

Let T:V→W be a linear transformation. Then for any vectors v1,…,vn∈V and scalars a1,…,an∈F: T(∑i=1naivi)=∑i=1naiT(vi).

Proof. By induction on n. The base case n=1 is homogeneity. For the inductive step: T(∑i=1n+1aivi)=T(∑i=1naivi+an+1vn+1)=T(∑i=1naivi)+T(an+1vn+1)(additivity)=∑i=1naiT(vi)+an+1T(vn+1)(induction + homogeneity)=∑i=1n+1aiT(vi).

2.1.5. Linear Transformation Determined by Basis

Another useful fact of a linear transformation is that once we know how it acts on a basis, then we know how it acts on every vector in the domain.

Theorem 2.1.5 (Linear Transformations are Determined by Their Action on a Basis)

Let T:V→W be a linear transformation and V is finite dimensional, and B={v1,…,vn} be a basis for V. Then we have:

  1. For every v∈V, f(v) is a linear combination of f(v1),f(v2),…,f(vn).
  2. Suppose the linear transformation g:V→W satisfies g(vi)=f(vi) for all i. Then g=f.

We say ‘f is determined by f(v1),…,f(vn)’ in this case.

Proof. Let v∈V. Since B is a basis of V, we can write v=α1v1+⋯+αnvn. Then f(v)=f(α1v1+⋯+αnvn)=α1f(v1)+⋯+αnf(vn). This proves the first condition.

Moreover, if g:V→W satisfies g(vi)=f(vi), then: g(v)=g(α1v1+⋯+αnvn)=α1g(v1)+⋯+αng(vn)=a1f(v1)+⋯+αnf(vn)=f(α1v1+⋯+αnvn)=f(v).

Since g(v)=f(v) for all v∈V, we have f=g. This finishes the second condition.

Example

Is it possible to have a linear map f:R2→R3 such that f(1,0)=(2,3,4),f(1,1)=(3,4,5),f(2,3)=(4,56)?

Solution. Idea: Since {(1,0),(1,1)} forms a basis of R2, these two function value would determine f completely.

Suppose such a linear transformation f exists. Observe that (2,3)=−1(1,0)+3(1,1).

Apply f then we have: f(2,3)=f(−1(1,0)+3(1,1))=−1f(1,0)+3f(1,1)=−1(2,3,4)+3(3,4,5)=(7,8,11)≠(4,56).

Which is inconsistent with the third equation, therefore no such transformation exists.

Example

Suppose we are give a linear transformation f:R[x]≤3→R[x]≤2. And it is also know that f(x3)=3x2,f(x2)=2x,f(x)=1,f(1)=0.

Solution. As {1,x,x2,x3} forms a basis of R[x]≤3. And D(xk)=f(xk), for k=0,1,2,3, as D is differentiation. We have that D≡f is the same linear transformation.

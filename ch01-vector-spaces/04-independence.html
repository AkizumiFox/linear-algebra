1.4  Linear Independence

A spanning set is like a toolbox that is guaranteed to have every tool you need. But a messy toolbox might have three different hammers that all do the same thing. In mathematics, as in engineering, we value efficiency.

If one of the vectors in your spanning set can already be built using the others, then that vector is “dead weight”—it isn’t helping you reach any new territory. We call such a set linearly dependent.

In this section, we search for the “cleanest” possible sets. We want to know: “Is every vector in this collection actually contributing something unique, or is someone just coasting on the work of the others?”

1.4.1. Definition and Examples

Definition 1.4.1 (Linear Independence)

A subset S of a vector space V is said to be linearly independent if for any distinct vectors v1,v2,…,vn∈S, the only solution to the equation: a1v1+a2v2+⋯+anvn=0 is the trivial solution a1=a2=⋯=an=0.

If there exists a non-trivial solution (where at least one ai≠0), then S is said to be linearly dependent.

Remark. Geometrically, in R2, two vectors are linearly dependent if and only if they lie on the same line through the origin (one is a multiple of the other). In R3, three vectors are linearly dependent if and only if they lie on the same plane through the origin.

Example (Examples of Linear Independence)

The following examples illustrate how to check for linear independence in various settings:

  1. Let S1={(1,2,3),(4,5,6)}⊆R3. To check linear independence, suppose a(1,2,3)+b(4,5,6)=(0,0,0)⟹{a+4b=02a+5b=03a+6b=0 The first two equations give a=−4b and 2(−4b)+5b=0⟹−3b=0. Thus a=b=0, so S1 is linearly independent.

  2. Let S2={(1,2,3),(4,5,6),(7,8,9)}⊆R3. Note that (1,2,3)−2(4,5,6)+(7,8,9)=(1−8+7,2−10+8,3−12+9)=(0,0,0). Since there exists a non-trivial solution, S2 is linearly dependent.

  3. Consider {2x+1,x2+3} in R[x]≤2. Suppose a(2x+1)+b(x2+3)=0⟹bx2+2ax+(a+3b)=0. Comparing coefficients of x2,x,1, we have b=0, 2a=0, and a+3b=0. This implies a=b=0, so the set is linearly independent.

  4. Consider {sin⁡x,cos⁡x,ex} in D(R). Suppose for all x∈R: asin⁡x+bcos⁡x+cex=0. Setting x=0 gives b+c=0. Setting x=π gives −b+ceπ=0. Adding these gives c(1+eπ)=0, so c=0 and hence b=0. Finally, setting x=π/2 gives a+ceπ/2=0⟹a=0. Thus, the set is linearly independent.

Theorem 1.4.1 (Linear Dependence Lemma)

{v1,v2,…,vm} is linearly dependent if and only if either v1=0 or for some r, vr is a linear combination of {v1,v2,…,vr−1}.

Proof. (⇒) Suppose S={v1,…,vm} is linearly dependent. Then there exist a1,…,am∈F, not all zero, such that a1v1+⋯+amvm=0. Let r be the largest index such that ar≠0. Then a1v1+⋯+ar−1vr−1+arvr=0. So arvr=−(a1v1+⋯+ar−1vr−1), and dividing by ar gives vr=−a1arv1−⋯−ar−1arvr−1. Hence vr is a linear combination of {v1,…,vr−1}. (If r=1, this says a1v1=0 with a1≠0, so v1=0.)

(⇐) We prove by cases:

  • If v1=0, then 1⋅v1+0⋅v2+⋯+0⋅vm=0, with coefficients not all zero, so S is linearly dependent.

  • If for some r we have vr is a linear combination of {v1,…,vr−1}, then there exist scalars c1,…,cr−1∈F such that vr=c1v1+⋯+cr−1vr−1. Move everything to one side: c1v1+⋯+cr−1vr−1−1⋅vr=0. Extending coefficients by zeros for vr+1,…,vm, we get a nontrivial linear combination of v1,…,vm equal to 0, so S is linearly dependent.

Remark. The above theorem can be paraphrased to: A set S={v1,…,vn} with n≥2 is linearly dependent if and only if at least one vector in S can be written as a linear combination of the others.

1.4.2. The Redundant Members

Having the last remark in mind, we can develop an intuition that says linear independence of a set is equivalent to requiring the set containing no “redundant members.” Next we want to develop the intuition saying that throwing away these “redundant members” will not change the linear span.

Theorem 1.4.2 (Span Preservation)

Let S={v1,…,vm,w}⊆V. If w∈span{v1,…,vm}, then span(S)=span{v1,…,vm}.

Proof. Let W=span{v1,…,vm} and W′=span(S). Since {v1,…,vm}⊆S, it is clear that W⊆W′.

For the reverse inclusion, let v∈W′. Then v is a linear combination of vectors in S: v=a1v1+⋯+amvm+bw for some scalars ai,b. Since w∈W, there exist scalars c1,…,cm such that w=c1v1+⋯+cmvm. Substituting this into the expression for v: v=a1v1+⋯+amvm+b(c1v1+⋯+cmvm)=(a1+bc1)v1+⋯+(am+bcm)vm. Thus v is a linear combination of v1,…,vm, so v∈W. This shows W′⊆W. Hence W′=W.

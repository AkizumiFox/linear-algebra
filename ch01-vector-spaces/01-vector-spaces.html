1.1  Vector Spaces

Chapter 0 met several kinds of objects that can be added and scaled: pairs of real numbers, polynomials, matrices. Each time we checked the same handful of rules by hand. This section collects those rules into one definition, the vector space, and proves the first consequences once, so that they hold in every example at the same time.

1.1.1. One set of rules in three places

Start with the plane R2. A pair u=(3,1) can be pictured as an arrow from the origin to the point (3,1). Two arrows are added tip to tail, which is the same as taking the diagonal of the parallelogram they span, and an arrow is scaled by stretching it.

The picture shows one rule at once: going along u and then v ends at the same corner as going along v and then u, so u+v=v+u. Other rules are just as familiar. Scaling a sum is the same as adding the scaled arrows, 2(u+v)=2u+2v. Adding the zero arrow changes nothing, and every arrow is undone by its reverse.

Now look at polynomials of degree at most 2. We add them coefficient by coefficient, (1+2x−x2)+(3−x+4x2)=4+x+3x2, and scale them the same way, 2(1+2x−x2)=2+4x−2x2. There is no picture of arrows here, yet the rules are identical: order does not matter in a sum, the zero polynomial changes nothing, and −1−2x+x2 undoes 1+2x−x2.

The same happens for 2×2 real matrices. Theorem 0.9.1 lists the rules for adding matrices and multiplying them by numbers, and they are again the same rules.

Arrows, polynomials and matrices are very different objects, but many arguments about them only use these rules. If we prove a statement from the rules alone, it holds for arrows, polynomials and matrices at once, and for every other system obeying the rules. So we list the rules once and give the systems that obey them a name.

A vector space is a set whose elements can be added and scaled by numbers from a field, with the usual rules of arithmetic.

1.1.2. The definition

Definition 1.1.1 (Vector Space)

Let F be a field. A vector space over F is a set V together with two functions +:V×V→V, (u,v)↦u+v,⋅:F×V→V, (a,v)↦av, called addition and scalar multiplication, such that the following axioms hold.

  • (VS1) u+v=v+u for all u,v∈V.
  • (VS2) (u+v)+w=u+(v+w) for all u,v,w∈V.
  • (VS3) There exists an element 0∈V such that v+0=v for every v∈V.
  • (VS4) For every v∈V there exists an element v′∈V such that v+v′=0.
  • (VS5) a(u+v)=au+av for all a∈F and u,v∈V.
  • (VS6) (a+b)v=av+bv for all a,b∈F and v∈V.
  • (VS7) a(bv)=(ab)v for all a,b∈F and v∈V.
  • (VS8) 1v=v for every v∈V, where 1 is the identity element of F.

Read the definition clause by clause.

  • The two functions. Addition takes two elements of V and returns an element of V. Scalar multiplication takes a number from F and an element of V and returns an element of V. So “the sum stays in the set” and “a multiple stays in the set” are not extra axioms: they are built into the word “function into V”. When we test a candidate, this closure is the first thing to check.
  • (VS1)–(VS4) concern addition alone. It is commutative and associative, there is a vector 0 that changes nothing, and every vector can be undone. These are the axioms (F1)–(F4) of Definition 0.7.1, now for vectors.
  • (VS5) and (VS6) are the two distributive laws. In (VS6) the symbol + appears twice with two meanings: on the left it adds scalars in F, on the right it adds vectors in V.
  • (VS7) says scaling by b and then by a is scaling by the product ab, computed in F.
  • (VS8) says the scalar 1 acts as it should. It looks too obvious to state, but we will see below that it cannot be dropped.

Note the order of quantifiers in (VS3): one vector 0 works for every v. In (VS4) the vector v′ is allowed to depend on v.

Definition 1.1.2 (Vectors and Scalars)

Let V be a vector space over F. The elements of V are called vectors, and the elements of F are called scalars. The element 0 in (VS3) is a zero vector of V, and an element v′ as in (VS4) is an additive inverse of v.

A vector space over R is also called a real vector space, and one over C a complex vector space. When the operations are clear from context, we say “V is a vector space over F” instead of naming the triple (V,+,⋅). The field is part of the data, and we will see shortly that changing it changes the space.

We wrote “a zero vector” and “an additive inverse” on purpose. The axioms only say these exist. That there is only one of each is a theorem, proved later in this section.

Warning. Two different zeros. The scalar 0∈F and the zero vector 0∈V are different objects. In M2(R), the scalar is the number 0 and the zero vector is the zero matrix; in R3, the zero vector is (0,0,0). This book writes the zero vector in bold. An equation such as 0v=0 has a scalar on the left and a vector on the right, and mixing them up produces statements that make no sense, such as “v=0” for a matrix v.

1.1.3. Examples

We start with the families we will use throughout the book. For each, the work is to say what the operations are and why the axioms hold. We check some axioms in full and point out the pattern for the rest.

Example (The Standard Vector Spaces)

Let F be a field. Explain why each of the following is a vector space over F.

  • (a) Fn, with entrywise addition and scalar multiplication.
  • (b) Mm×n(F), with the matrix operations of Definition 0.9.6 and Definition 0.9.7.
  • (c) F[x], with the addition of Definition 0.8.2 and c∑akxk:=∑(cak)xk.
  • (d) For a set X, the set FX of all functions X→F, with the pointwise operations (f+g)(t):=f(t)+g(t),(af)(t):=af(t)for all t∈X.
  • (e) The set FN of all sequences (s0,s1,s2,…) of elements of F, with termwise operations.

Solution.

  • (b) The sum and scalar multiple of m×n matrices are m×n matrices, so both operations are functions into Mm×n(F). The eight axioms are exactly the rules of Theorem 0.9.1, with the zero matrix as 0 and −A as an additive inverse of A.

  • (c) Chapter 0 defines Fn=Mn×1(F), the column vectors, and the entrywise operations are the matrix operations. So (a) is the case of (b) with n rows and 1 column. The zero vector is (0,…,0).

  • (d) The formulas define functions f+g and af from X to F, so the operations land in FX. Two functions X→F are equal when they take the same value at every t∈X (Definition 0.4.1), so each axiom is checked one point at a time. For (VS3), let 0 be the zero function, 0(t)=0 for all t. Then (f+0)(t)=f(t)+0=f(t) for every t, by (F3), so f+0=f. For (VS4), let f′(t):=−f(t). Then (f+f′)(t)=f(t)+(−f(t))=0=0(t) by (F4), so f+f′=0. For (VS6), let a,b∈F. For every t∈X, ((a+b)f)(t)=(a+b)f(t)=af(t)+bf(t)=(af)(t)+(bf)(t)=(af+bf)(t), where the second equality is (F9) together with (F6) in F. Hence (a+b)f=af+bf. The other five axioms reduce in the same way to a field axiom at each point: (VS1) to (F1), (VS2) to (F2), (VS5) to (F9), (VS7) to (F5), and (VS8) to (F7) with (F6).

  • (e) A sequence (s0,s1,…) is a function N→F, k↦sk, and the termwise operations are the pointwise ones. So (e) is (d) with X=N.

  • (f) Let p=∑akxk∈F[x] and c∈F. Only finitely many ak are non-zero, and ak=0 forces cak=0, so cp is again a polynomial. The sum of polynomials is a polynomial by Definition 0.8.2. By Theorem 0.8.1 (parts 1 and 2), addition satisfies (VS1)–(VS4), with the zero polynomial as 0 and −p as an additive inverse. Since polynomials are equal when their coefficients agree (Definition 0.8.1), (VS5)–(VS8) are checked coefficient by coefficient. For instance, the coefficient of xk in (c+d)p is (c+d)ak=cak+dak, which is the coefficient of xk in cp+dp. The others reduce in the same way: (VS5) to (F9), (VS7) to (F5), and (VS8) to (F7) with (F6).

The pattern is worth naming. Whenever the operations are defined entry by entry, point by point or coefficient by coefficient, each axiom for vectors is a field axiom applied in each slot. In fact (a), (b) and (e) are all instances of (d): a column in Fn is a function {1,…,n}→F, and a matrix in Mm×n(F) is a function on the set of positions {1,…,m}×{1,…,n}.

A subset of a known space often works just as well, provided the operations do not lead out of it.

The set F[x]≤n of Definition 0.8.4 is a vector space over F, with the operations of F[x]. Closure is the only real issue. If deg⁡p≤n and deg⁡q≤n, then deg⁡(p+q)≤max(deg⁡p,deg⁡q)≤n by Theorem 0.8.2. If ak=0 for all k>n, then cak=0 for all k>n, so deg⁡(cp)≤n. The zero polynomial has degree −∞≤n, and −p has the same coefficients as p up to sign, so it stays in F[x]≤n. The six axioms (VS1), (VS2), (VS5)–(VS8) are equations that hold for all polynomials, so in particular for those of degree at most n.

The next example applies the same pattern to a set of real numbers, with a smaller field of scalars.

Example (Q(2) over Q)

Let Q(2)={a+b2:a,b∈Q}, with the addition of R and with scalar multiplication c(a+b2):=ca+cb2 for c∈Q. Show that Q(2) is a vector space over Q.

Solution. Let u=a+b2 and v=a′+b′2 with a,b,a′,b′∈Q, and let c∈Q.

Closure. We have u+v=(a+a′)+(b+b′)2 and cu=ca+cb2. Sums and products of rationals are rational, so both lie in Q(2). Hence addition is a function Q(2)×Q(2)→Q(2), and scalar multiplication is a function Q×Q(2)→Q(2).

Zero and additive inverses. The number 0=0+02 lies in Q(2) and satisfies u+0=u, so (VS3) holds. The number −u=(−a)+(−b)2 lies in Q(2) and satisfies u+(−u)=0, so (VS4) holds.

The identities. Scalar multiplication by c∈Q is the multiplication of real numbers, since c(a+b2)=ca+cb2 in R. So each of (VS1), (VS2) and (VS5)–(VS8) is an identity between real numbers, and it holds by the field axioms of R: (VS1) is (F1), (VS2) is (F2), (VS5) is (F9), (VS6) is (F9) with (F6), (VS7) is (F5), and (VS8) is (F7) with (F6). Hence Q(2) is a vector space over Q.

We saw in Example (Q(2) Is a Field) that Q(2) is even a field. As a vector space over Q, we simply ignore how to multiply two of its elements together and keep only multiplication by rationals.

The same set can carry more than one field of scalars. The next example makes this concrete.

Example (The Same Set over Different Fields)

Explain why C is a vector space over C and also over R, and why R is a vector space over R and also over Q. In each case the addition is the usual one and the scalar multiplication is the usual product.

Solution. C over C is F1 for F=C, covered by Example (The Standard Vector Spaces) (a). For C over R, a real number r is the complex number r+0i, and rz is their complex product, which lies in C. Each axiom is an identity among complex numbers in which some of the numbers happen to be real, so it holds by Proposition 0.6.1: (VS5) and (VS6) by distributivity together with commutativity, (VS7) by associativity of multiplication, and (VS8) since 1⋅z=z. The argument for R over Q is the same, with the field axioms of R in place of the laws of C.

As sets, C over C and C over R are the same. As vector spaces they differ, because the scalars available differ. In C over C, the vector i is a scalar multiple of the vector 1. In C over R it is not, since r⋅1=i has no real solution r. Later in this chapter this difference becomes a difference in dimension. That is why we always say over which field.

The degenerate case. The set {0} with one element, with 0+0=0 and a0=0 for every a∈F, is a vector space over any field. Every axiom is an equation between elements that all equal 0, and 0 serves as the zero vector and as its own additive inverse. It is called the zero space. It matters because it turns up constantly as an answer: the only solution of a system, or the smallest vector space inside every other one. Unlike a field, which must contain 1≠0 (Definition 0.7.1), a vector space is allowed to have a single element, since no axiom asks for a vector different from 0.

A final example looks strange, but it satisfies every axiom.

Example (Positive Reals with Exotic Operations)

Let V=R>0={t∈R:t>0}. For u,v∈V and c∈R, define u⊞v:=uv,c⊡v:=vc. Show that these operations are functions into V, find the zero vector and the additive inverse of v, and check (VS6) and (VS8).

Solution. Closure. For u,v>0 and c∈R, the product uv is positive and the power vc is positive. So ⊞:V×V→V and ⊡:R×V→V.

(VS3). We need z∈V with v⊞z=v, that is, vz=v, for every v>0. The number z=1 works, since v⋅1=v. So the zero vector of V is the real number 1.

(VS4). For v∈V, we need v′∈V with v⊞v′=1, that is, vv′=1. The number v′=1/v is positive and works. So the additive inverse of v is 1/v.

(VS6). For a,b∈R and v∈V, by the laws of exponents, (a+b)⊡v=va+b=vavb=(a⊡v)⊞(b⊡v).

(VS8). 1⊡v=v1=v.

The remaining axioms (VS1), (VS2), (VS5) and (VS7) are Exercise (B3: Finishing the Positive Reals). So V is a real vector space.

This example earns its place for one reason. The words “zero vector” and “addition” describe roles fixed by the axioms, not the familiar number 0 or the familiar +. Here the vector playing the role of 0 is the number 1, and “adding” means multiplying.

Quick check. Explain why each of the following, with the usual operations, is a vector space over R.

  • (a) The set S of twice-differentiable functions f:R→R with f″+f=0.
  • (b) The set of symmetric matrices A∈M2(R), that is, those with A⊤=A.

Solution. Both are subsets of known spaces, so we use the pattern after Example (The Standard Vector Spaces): check closure, the zero vector and additive inverses; the other six axioms are identities inherited from the big space.

  • (a) S⊆RR. If f,g∈S and c∈R, then by the sum and constant multiple rules of calculus, f+g and cf are twice differentiable, with (f+g)″+(f+g)=(f″+f)+(g″+g)=0 and (cf)″+cf=c(f″+f)=0. So both lie in S. The zero function 0 satisfies 0″+0=0, so 0∈S. If f∈S, its additive inverse in RR is t↦−f(t), and −f(t)=(−1)f(t) by Theorem 0.7.1 (e); so it is the function (−1)f, which lies in S by closure under scaling. The identities hold in RR (Example (The Standard Vector Spaces) (d)), hence in S. For instance sin and cos lie in S.

  • (b) By Theorem 0.9.5, (A+B)⊤=A⊤+B⊤=A+B and (cA)⊤=cA⊤=cA when A⊤=A and B⊤=B. The zero matrix is symmetric, and the additive inverse −A, which Chapter 0 defines as (−1)A, is symmetric by closure under scaling. The identities hold in M2(R), hence for symmetric matrices.

1.1.4. Non-examples

Each non-example below is a small change to an example. We say what still works and name the exact clause that fails.

  • Change scalar multiplication on R2 to c(x,y):=(cx,0), keeping the usual addition. Addition is untouched, so (VS1)–(VS4) hold. (VS5) holds: c((x,y)+(x′,y′))=(c(x+x′),0)=(cx,0)+(cx′,0). In the same way (VS6) and (VS7) hold. But 1(0,1)=(0,0)≠(0,1), so (VS8) fails.
  • Change the line x+2y=0 to x+2y=3. Let L={(x,y)∈R2:x+2y=3} with the operations of R2. The points (3,0) and (1,1) lie on L, but their sum (4,1) has 4+2⋅1=6≠3. So addition is not a function L×L→L, and L is not a vector space with these operations.
  • Change “degree at most 2” to “degree exactly 2”. In R[x]=2 (Definition 0.8.5), x2+2x and −x2+3 have degree 2, but their sum 2x+3 has degree 1. Again addition leaves the set. There is no zero vector either: the zero polynomial has degree −∞, not 2.
  • Change the entries from real to integer, keeping R as the field. For Z2⊆R2, addition is fine, but 12(1,0)=(12,0)∉Z2. So scalar multiplication is not a function R×Z2→Z2.

1.1.5. Why these axioms

Each axiom is there for a reason, and a few conventions deserve a comment.

  • (VS8) cannot be dropped. The first non-example satisfies all other axioms. Without (VS8), the “scalar multiplication” cv=0 for all c and v would also be allowed, and scaling would carry no information at all.
  • (VS1) is in fact redundant. Commutativity of addition follows from the other seven axioms, by expanding (1+1)(u+v) in two ways (Exercise (C1: Commutativity Comes for Free)). It is kept because the proof is fiddly and nobody wants to repeat it.
  • Closure is not optional. Two of the non-examples fail only because an operation leads out of the set. That is why the definition asks for functions into V.
  • The scalars form a field. We use division by non-zero scalars in the zero product law at the end of the next subsection. The warning after it shows what goes wrong without division.
  • The name. “Vector” originally meant an arrow in physics. The word is kept for elements of any vector space, even when they are polynomials or functions.

1.1.6. First consequences of the axioms

The definition says a zero vector and additive inverses exist, not that they are unique. Before writing 0 and −v as if each named one thing, we prove uniqueness. We also prove that familiar rules such as 0v=0 follow from the axioms. None of this is obvious from the axioms: in Example (Positive Reals with Exotic Operations), 0⊡v=v0=1, which happens to be the zero vector there, and it takes a proof to see that this is no coincidence.

Throughout, we use one fact about functions without further comment: if two inputs are equal, the outputs are equal. So from v=w we may conclude u+v=u+w and av=aw.

The first tool lets us cancel a vector from both sides of an equation.

Theorem 1.1.1 (Left Cancellation Law)

Let V be a vector space over F and let u,v,w∈V. If u+v=u+w, then v=w.

Proof. Suppose u+v=u+w. By (VS4) there is u′∈V with u+u′=0. Adding u′ on the left of both sides gives u′+(u+v)=u′+(u+w), and by (VS2), (u′+u)+v=(u′+u)+w. By (VS1) and the choice of u′, u′+u=u+u′=0. Hence 0+v=0+w. By (VS1) this is v+0=w+0, and by (VS3), v=w.

Theorem 1.1.2 (Right Cancellation Law)

Let V be a vector space over F and let u,v,w∈V. If v+u=w+u, then v=w.

Proof. By (VS1), the hypothesis says u+v=u+w. By Theorem 1.1.1, v=w.

Uniqueness uses the standard move from Chapter 0: suppose there are two, and show they are equal.

Theorem 1.1.3 (Zero Vector Is Unique)

Let V be a vector space over F. There is exactly one element 0∈V satisfying (VS3).

Proof. Existence is (VS3). Suppose 0 and 0′ both satisfy (VS3). Applying (VS3) for 0′ to the vector 0, then (VS1), then (VS3) for 0 to the vector 0′, 0=0+0′=0′+0=0′. This shows the zero vector is unique.

Theorem 1.1.4 (Additive Inverse Is Unique)

Let V be a vector space over F and v∈V. There is exactly one v′∈V with v+v′=0.

Proof. Existence is (VS4). Suppose v+v′=0 and v+v″=0. Then v+v′=v+v″, and Theorem 1.1.1 gives v′=v″.

Since the inverse is unique, it deserves a name.

Definition 1.1.3 (Notation for the Additive Inverse)

Let V be a vector space over F and v∈V. The unique additive inverse of v is denoted −v. For u,v∈V we write u−v:=u+(−v).

For example, v+(−v)=0 and (−v)+v=0 by (VS1), so v is the additive inverse of −v. By Theorem 1.1.4, −(−v)=v.

Remark. Axioms (VS1)–(VS4) say that V with addition is an abelian group (Definition 0.10.1). So the four results above are also special cases of Theorem 0.10.1. We proved them directly to practice citing the axioms.

Now to scalars. No axiom mentions 0v, so we must create a situation in which one applies. The move is to write the scalar 0 in a fancy way, as 0+0, expand with a distributive law, and cancel. We will call it expand zero and cancel.

Theorem 1.1.5 (Zero Scalar Gives the Zero Vector)

Let V be a vector space over F. Then 0v=0 for every v∈V.

Proof. Let v∈V. Since 0+0=0 in F by (F3), (VS6) gives 0v+0v=(0+0)v=0v=0v+0, where the last equality is (VS3). By Theorem 1.1.1, 0v=0.

The same move, with the zero vector in place of the zero scalar, handles a0.

Theorem 1.1.6 (Scalar Multiple of the Zero Vector)

Let V be a vector space over F. Then a0=0 for every a∈F.

Proof. Let a∈F. Since 0+0=0 by (VS3), (VS5) gives a0+a0=a(0+0)=a0=a0+0, where the last equality is (VS3). By Theorem 1.1.1, a0=0.

To identify a vector as −v, it is enough to show it adds with v to 0, by Theorem 1.1.4. This gives the next two results.

Theorem 1.1.7 (Negation as Scalar Multiplication)

Let V be a vector space over F. Then (−1)v=−v for every v∈V.

Proof. Let v∈V. By (VS8), (VS6), (F4) and Theorem 1.1.5, v+(−1)v=1v+(−1)v=(1+(−1))v=0v=0. So (−1)v is an additive inverse of v, and by Theorem 1.1.4 it equals −v.

Theorem 1.1.8 (Negative Scalars)

Let V be a vector space over F. Then (−a)v=−(av) for every a∈F and v∈V.

Proof. Let a∈F and v∈V. By (VS6), (F4) and Theorem 1.1.5, av+(−a)v=(a+(−a))v=0v=0. So (−a)v is an additive inverse of av, and by Theorem 1.1.4 it equals −(av).

The companion rules a(−v)=−(av) and a(u−v)=au−av are Exercise (B2: More Rules for Signs). From now on, we compute with +, − and scalars as in school algebra, citing these results when a step is not a single axiom.

The last result is the one we will use most. In a field, a product of non-zero numbers is non-zero (Theorem 0.7.1 (f)). The same holds for a scalar times a vector.

Theorem 1.1.9 (Zero Product Law)

Let V be a vector space over F, let a∈F and v∈V. Then av=0 if and only if a=0 or v=0.

Idea. The direction (⇐) is the two zero results above, Theorem 1.1.5 and Theorem 1.1.6. For (⇒), the only way to get rid of a is to multiply by a−1, and that is exactly where the hypothesis a≠0 and the field axiom (F8) are spent.

Proof. (⇐) If a=0, then av=0 by Theorem 1.1.5. If v=0, then av=0 by Theorem 1.1.6.

(⇒) Suppose av=0. If a=0 there is nothing to prove, so suppose a≠0. By (F8), a has an inverse a−1∈F. Then v=1v=(a−1a)v=a−1(av)=a−10=0, by (VS8), (F8) with (F6), (VS7), the hypothesis, and Theorem 1.1.6. This shows a=0 or v=0.

Warning. The zero product law needs division by scalars. Suppose we allowed integer “scalars” and let V=F2={0,1} with its own addition, where n⋅v is v for odd n and 0 for even n (for n≥0 this is v+⋯+v with n terms). Every rule of the shape (VS1)–(VS8) still holds. But 2⋅1=1+1=0, although 2≠0 in Z and 1≠0 in V. The proof above breaks exactly where it multiplies by a−1: the integer 2 has no inverse in Z. This is one reason vector spaces are defined over a field.

As a first use, here is a fact about sizes. Let v≠0 be a vector in a space over R. If av=bv, then (a−b)v=av−bv=0 by (VS6) and Theorem 1.1.8, so a=b by Theorem 1.1.9. So the multiples av, a∈R, are all different, and a real vector space other than {0} has infinitely many elements (Exercise (C2: How Big Is a Vector Space?) treats a general field). This is our first glimpse of the question at the heart of this chapter: all these spaces are infinite sets, so how should we measure their size? The next section starts on the answer by looking at the vector spaces that sit inside a given one.

1.1.7. Exercises

A. Check your understanding

Exercise (A1)
  • (a) State the eight axioms of a vector space over a field F, and say which of them involve scalars.
  • (b) Identify the zero vector in each of: M2×3(R); R[x]≤2; RR; the space R>0 of Example (Positive Reals with Exotic Operations).
  • (c) True or false: a vector space can have exactly two elements. Justify your answer.
  • (d) True or false: in every vector space, v+v=0 implies v=0. Justify your answer.
  • (e) True or false: if av=bv and v≠0, then a=b. Justify your answer.

Solution.

  • (a) See Definition 1.1.1. The axioms (VS5)–(VS8) involve scalars; (VS1)–(VS4) involve only addition.

  • (b) The zero matrix of size 2×3; the zero polynomial; the zero function t↦0; the number 1 (Example (Positive Reals with Exotic Operations)).

  • (c) True. Let F=F2. By Example (The Standard Vector Spaces) (a), F21=F2={0,1} is a vector space over F2, and it has exactly two elements.

  • (d) False. In the vector space F2 over F2 from (c), the vector 1≠0 satisfies 1+1=0. (Over R the statement is true: v+v=(1+1)v=2v by (VS8) and (VS6), and 2≠0, so v=0 by Theorem 1.1.9.)

  • (e) True. By (VS6) and Theorem 1.1.8, (a−b)v=av+(−b)v=av−bv=0. Since v≠0, Theorem 1.1.9 gives a−b=0, so a=b.

Exercise (B1: Which Are Vector Spaces?)

Determine which of the following are vector spaces. Justify your answer.

  • (a) R2 over R, with the usual scalar multiplication but with addition (x,y)+(x′,y′):=(x+x′,0).
  • (b) The set of upper triangular matrices in M2(R), over R, with the matrix operations.
  • (c) {p∈R[x]:p(1)=0}, over R, with the operations of R[x].
  • (d) {p∈R[x]:p(1)=1}, over R, with the operations of R[x].
  • (e) R2 over C, with c(x,y):=(cx,cy) and the usual addition.

Solution.

  • (a) Not a vector space: (VS3) fails. Suppose 0=(z1,z2) satisfied (VS3). Then (0,1)+(z1,z2)=(z1,0) would equal (0,1), which is impossible since the second entries differ.

  • (b) A vector space. Let A=(ab0d) and B=(a′b′0d′) be upper triangular and c∈R. Then A+B=(a+a′b+b′0d+d′) and cA=(cacb0cd) are upper triangular, so the operations land in the set. The zero matrix is upper triangular, and so is −A=(−1)A. The identities (VS1), (VS2), (VS5)–(VS8) hold for all matrices in M2(R) by Example (The Standard Vector Spaces) (b), hence for upper triangular ones.

  • (c) A vector space. Let U={p∈R[x]:p(1)=0}, p,q∈U and c∈R. By Theorem 0.8.5, (p+q)(1)=p(1)+q(1)=0. Also cp is the product of the constant polynomial c with p, since by the product formula of Definition 0.8.2 that product has coefficients cak. So (cp)(1)=cp(1)=0. Hence p+q,cp∈U. The zero polynomial has value 0 at 1, and −p=(−1)p∈U by closure under scaling. The identities hold in R[x] by Example (The Standard Vector Spaces) (c), hence in U.

  • (d) Not a vector space: addition leaves the set. The constant polynomial 1 lies in the set, but (1+1)(1)=2≠1, so 1+1 does not.

  • (e) Not a vector space: scalar multiplication leaves the set. We have i∈C and (1,0)∈R2, but i(1,0)=(i,0)∉R2. So the rule is not a function C×R2→R2.

Exercise (B2: More Rules for Signs)

Let V be a vector space over F, let a,b∈F and u,v∈V. Prove that:

  • (a) a(−v)=−(av);
  • (b) (−a)(−v)=av;
  • (c) a(u−v)=au−av and (a−b)v=av−bv.

Hint: to show a vector equals −(av), use Theorem 1.1.4.

Solution.

  • (a) By (VS5), (VS4) and Theorem 1.1.6, av+a(−v)=a(v+(−v))=a0=0. So a(−v) is an additive inverse of av. By Theorem 1.1.4, a(−v)=−(av).

  • (b) By (a) applied with the scalar −a, then Theorem 1.1.8, then the remark after Definition 1.1.3, (−a)(−v)=−((−a)v)=−(−(av))=av.

  • (c) By Definition 1.1.3, (VS5) and (a), a(u−v)=a(u+(−v))=au+a(−v)=au+(−(av))=au−av. Similarly, since a−b=a+(−b) in F, (VS6) and Theorem 1.1.8 give (a−b)v=av+(−b)v=av+(−(bv))=av−bv.

Exercise (B3: Finishing the Positive Reals)

Let V=R>0 with the operations ⊞ and ⊡ of Example (Positive Reals with Exotic Operations).

  • (a) Verify (VS1), (VS2), (VS5) and (VS7). Hence V is a vector space over R.
  • (b) Compute the vector (2⊡3)⊞((−1)⊡6).
  • (c) Find the vector −(2⊡3), and check your answer against Theorem 1.1.8.

Solution.

  • (a) Let u,v,w∈V and a,b∈R. By the laws of real multiplication and of exponents for positive bases:
    • (VS1): u⊞v=uv=vu=v⊞u.
    • (VS2): (u⊞v)⊞w=(uv)w=u(vw)=u⊞(v⊞w).
    • (VS5): a⊡(u⊞v)=(uv)a=uava=(a⊡u)⊞(a⊡v).
    • (VS7): a⊡(b⊡v)=(vb)a=vab=(ab)⊡v.

    Together with closure, (VS3), (VS4), (VS6) and (VS8) from Example (Positive Reals with Exotic Operations), all eight axioms hold. Hence V is a vector space over R.

  • (b) 2⊡3=32=9 and (−1)⊡6=6−1=16. So the vector is 9⊞16=9⋅16=32.

  • (c) By Example (Positive Reals with Exotic Operations), the additive inverse of a vector v is 1/v. Since 2⊡3=9, we get −(2⊡3)=19. By Theorem 1.1.8, this should equal (−2)⊡3=3−2=19, and it does.

C. Going deeper

Exercise (C1: Commutativity Comes for Free)

Let V be a set with operations +:V×V→V and ⋅:F×V→V satisfying (VS2)–(VS8), but not necessarily (VS1). Fix 0 as in (VS3).

  • (a) Let v∈V and v′ as in (VS4). Put w=v′+v. Show that w+w=w, and deduce that w=0.
  • (b) Show that 0+v=v for every v∈V.
  • (c) Deduce that both cancellation laws hold: u+v=u+w implies v=w, and v+u=w+u implies v=w.
  • (d) By expanding (1+1)(u+v) in two ways, prove that u+v=v+u for all u,v∈V.

Hint: in (a), add an additive inverse of w on the right. The proof of Theorem 1.1.1 used (VS1), so it cannot be quoted in (c).

Solution. Throughout we use only (VS2)–(VS8), and we drop brackets in sums whenever (VS2) allows it.

  • (a) Since v+v′=0 and v′+0=v′ by (VS3), w+w=v′+(v+v′)+v=v′+0+v=v′+v=w. By (VS4) choose w′ with w+w′=0. Adding w′ on the right of w+w=w gives w+(w+w′)=w+w′, that is, w+0=0. By (VS3), w=0. So v′+v=0 as well.

  • (b) Let v∈V and v′ as in (VS4). By (a), (VS2) and (VS3), 0+v=(v+v′)+v=v+(v′+v)=v+0=v.

  • (c) Suppose u+v=u+w, and let u′ be as in (VS4). Adding u′ on the left and using (VS2), (u′+u)+v=(u′+u)+w. By (a), u′+u=0, so 0+v=0+w, and (b) gives v=w. Now suppose v+u=w+u. Adding u′ on the right and using (VS2), v+(u+u′)=w+(u+u′), so v+0=w+0, and (VS3) gives v=w.

  • (d) Let u,v∈V. On the one hand, by (VS6) and (VS8), (1+1)(u+v)=1(u+v)+1(u+v)=u+v+u+v. On the other hand, by (VS5), then (VS6) and (VS8), (1+1)(u+v)=(1+1)u+(1+1)v=u+u+v+v. Hence u+(v+u)+v=u+(u+v)+v, grouping by (VS2). Canceling u on the left and then v on the right, by (c), gives v+u=u+v. This proves (VS1).

Exercise (C2: How Big Is a Vector Space?)
  • (a) Let F be an infinite field and V≠{0} a vector space over F. Prove that V is an infinite set.
  • (b) Let p be a prime and n≥1. How many elements does the vector space Fpn over Fp have? Explain why this does not contradict (a).

Hint: for (a), fix v≠0 and consider the function F→V, a↦av.

Solution.

  • (a) Since V≠{0} and 0∈V, there is v∈V with v≠0. Consider φ:F→V, φ(a)=av. Suppose φ(a)=φ(b), so av=bv. By Exercise (B2: More Rules for Signs) (c), (a−b)v=av−bv=0. Since v≠0, Theorem 1.1.9 gives a−b=0, so a=b. Therefore φ is injective. An injective function from an infinite set has an infinite image, so V, which contains the image of φ, is infinite.

  • (b) An element of Fpn is a list (x1,…,xn) with each xi chosen freely from the p elements of Fp. So Fpn has pn elements. There is no contradiction, because (a) assumes the field is infinite and Fp is finite. The proof of (a) still shows that a↦av is injective, so a non-zero space over Fp has at least p elements.

Exercise (C3: Shrinking the Field)

Let F be a field and let K⊆F be a subset with 0,1∈K that is closed under addition, multiplication, negatives, and inverses of non-zero elements. (So K is itself a field with the operations of F; for example Q⊆R⊆C.)

  • (a) Let V be a vector space over F. Prove that V, with the same addition and with scalar multiplication restricted to K×V, is a vector space over K.
  • (b) Deduce that Cn is a vector space over R and over Q.
  • (c) Explain why R, with its usual addition and multiplication, is not a vector space over C.

Solution.

  • (a) The addition is unchanged, so it is a function V×V→V satisfying (VS1)–(VS4). Scalar multiplication F×V→V restricts to a function K×V→V, since K⊆F. The axioms (VS5)–(VS7) are statements about all scalars in F, so they hold in particular for all scalars in K; the operations a+b and ab appearing in them are the same in K as in F. For (VS8), the identity of K is the identity 1 of F, and 1v=v holds in V over F. Hence V is a vector space over K.

  • (b) Cn is a vector space over C by Example (The Standard Vector Spaces) (a). The subsets R⊆C and Q⊆C contain 0 and 1 and are closed under the four operations, so (a) applies to both.

  • (c) The only candidate for scalar multiplication is (c,t)↦ct, the product in C. But it does not land in R: i∈C and 1∈R, while i⋅1=i∉R. So there is no function C×R→R given by this rule, and R is not a vector space over C with these operations.

## 01-linear-systems.md — Three views of a linear system

- **Hook:** the same 2×2 system three ways: two lines meeting (row picture, TikZ); a combination of two column vectors hitting b (column picture, TikZ); the matrix equation Ax = b.
- **Definitions:**
  - `def-linear-system`: a system of m equations in n unknowns over F; coefficient matrix, augmented matrix; solution, solution set; consistent/inconsistent.
  - `def-homogeneous-system`.
- **Theorem** `thm-consistent-iff-column-span`: Ax = b is consistent ⇔ b ∈ span(columns of A). Uses `thm-matrix-times-vector-columns`.
- **Theorem** `thm-homogeneous-solutions-subspace`: the solution set of Ax = 0 is a subspace of Fⁿ. Recall `exm-null-space-subspace` from Ch 1 and link to it.
- **Theorem** `thm-general-solution-structure`: if p is one solution of Ax = b, the solution set is p + {solutions of Ax = 0}. This is the "particular + homogeneous" move. Picture: a parallel line not through 0.
- **Corollary** `cor-unique-solution-iff-trivial-kernel`: a consistent system has exactly one solution ⇔ Ax = 0 has only the trivial solution ⇔ the columns of A are linearly independent.
- **Warning:** the solution set of Ax = b with b ≠ 0 is **not** a subspace.
- **Examples:** inconsistent (parallel lines); unique; infinitely many; a system over 𝔽₂ with exactly 2 solutions.
- **Check.**
- **Exercises:**
  - **A.**
  - **B:** write systems in the three views; decide whether b is in a span by setting up a system; solve small systems by substitution and describe the solution set as p + span.
  - **C:** show a system over an infinite field has 0, 1 or infinitely many solutions (using the structure theorem); over 𝔽_q the number of solutions is 0 or a power of q (the power claim is proved later, in 05 — here only "0 or |null set|").

## 02-gaussian-elimination.md — Gaussian elimination

- **Hook:** the reader already eliminates variables by hand. Make it an algorithm and prove it never changes the answer.
- **Definitions:**
  - `def-elementary-row-operations`: swap; scale by c **≠ 0**; add c times one row to another.
  - `def-row-equivalent` (A → B by finitely many row operations). Link to Ch 0 `exm-row-equivalence`; the elementary-matrix version comes in 04.
- **Theorem** `thm-row-ops-preserve-solutions`: row operations are reversible and preserve the solution set. **Bold c ≠ 0.** Warning: scaling by 0 destroys information.
- **Echelon forms:** `def-row-echelon-form`, `def-reduced-row-echelon-form`; pivots, pivot columns, free variables.
- **Algorithm** (`::: {.algorithm}`): Gauss–Jordan.
  - **Theorem** `thm-rref-exists`: every matrix is row equivalent to a matrix in RREF. Proof by induction on the number of columns, or rows. Precise but readable.
- **Worked examples:**
  - a 3×4 system, reduced step by step, with the operations named at each arrow: `exm-gauss-jordan-3x4`;
  - over 𝔽₂: `exm-elimination-f2`.
- **Reading solutions** — `thm-reading-rref`:
  - the system is inconsistent ⇔ the RREF of [A | b] has a pivot in the last column;
  - otherwise, free variables parametrize the solutions, and the particular solution comes from setting the free variables to 0.
- **Counting** — `cor-more-unknowns-than-equations`: a homogeneous system with n > m has a non-trivial solution. **Important:** this gives an independent proof that m + 1 vectors in F^m are dependent, in agreement with Steinitz.
- **Warnings:**
  - different sequences of operations give different echelon forms, but the same **reduced** form (proved in 03);
  - column operations change the solution set.
- **Interactive** (optional): a `{.python .run}` cell using sympy's `Matrix.rref()` to check a hand computation.
- **Check.**
- **Exercises:**
  - **A.**
  - **B:** reduce and solve three systems (one inconsistent, one unique, one with 2 free variables); a system with a parameter k (for which k is it inconsistent / unique / infinite); solve over 𝔽₃.
  - **C:** show that the row operation "add c·row i to row i" is not always reversible, and why the definition requires i ≠ j; count the operations of Gauss–Jordan on an n×n matrix (order n³).

## 03-rref-uniqueness.md — Uniqueness of the reduced form

Short: ≈2,500 words.

- **Hook:** we promised that the RREF does not depend on the choices made. Why do we care? Rank and pivot columns are defined from it.
- **Lemma** `lem-row-equivalent-same-null-space`: row-equivalent matrices have the same solutions of Ax = 0. From `thm-row-ops-preserve-solutions`.
- **Theorem** `thm-rref-unique`: two matrices in RREF with the same null space are equal. Hence each matrix has a unique RREF.
  - **Idea:** the pivot columns are exactly the columns that are not combinations of earlier columns, and a column dependence \( \sum c_j \text{col}_j = 0 \) is exactly a null vector.
  - **Proof:** row operations preserve linear relations among columns (`lem-row-ops-preserve-column-relations`). In an RREF, the pivot columns are the first columns not in the span of earlier columns, and a non-pivot column's entries are its coefficients on earlier pivot columns. So the RREF is determined by the column relations.
- **Corollary** `cor-pivot-columns-well-defined`: the set of pivot columns of A is well defined.
- **Examples:** two different echelon forms of the same matrix with the same RREF.
- **Check.**
- **Exercises:**
  - **A.**
  - **B:** find the column relations of a matrix from its RREF; decide whether two matrices are row equivalent by comparing RREFs.
  - **C:** how many 2×3 RREF matrices are there over 𝔽₂? (Count by pivot pattern.)

## 04-elementary-matrices-and-inverses.md — Elementary matrices and inverses

- **Hook:** a row operation is multiplication on the left by a matrix, so the algorithm becomes algebra.
- **Definition** `def-elementary-matrix`.
  - **Theorem** `thm-row-op-is-left-multiplication`.
  - **Theorem** `thm-elementary-invertible`, with explicit inverses.
- **Theorem** `thm-invertible-tfae` (the invertible-matrix theorem, first version). For A ∈ M_n(F), TFAE:
  1. A is invertible;
  2. Ax = 0 has only the trivial solution;
  3. the RREF of A is I;
  4. A is a product of elementary matrices;
  5. Ax = b has a solution for every b;
  6. the columns of A are independent;
  7. the columns span Fⁿ;
  8. the columns form a basis.

  Give a proof cycle with care: each arrow names its reason. Say this list will grow in Ch 3, 6, 8 and 12.
- **Theorem** `thm-one-sided-inverse`: if A, B ∈ M_n(F) and AB = I, then BA = I and B = A⁻¹. **Proof:** Bx = 0 ⇒ x = ABx = 0, so B is invertible by the TFAE; then A = A(BB⁻¹) = (AB)B⁻¹ = B⁻¹. Pays off the Ch 0 promise.
- **Algorithm:** inverse by row reducing [A | I].
  - **Theorem** `thm-inverse-by-row-reduction`, with a proof via elementary matrices.
  - **Worked:** a 3×3 inverse (`exm-inverse-3x3`), and a failing case where a zero row appears.
- **Row equivalence:** B = EA with E invertible — `thm-row-equivalent-iff-invertible-multiple`. Connect to Ch 0 `exm-row-equivalence`.
- **Warning:** for non-square A, a one-sided inverse need not be two-sided. Give A with a right inverse but no left inverse (2×3).
- **Check.**
- **Exercises:**
  - **A.**
  - **B:** inverses of 3×3 matrices, including one non-invertible; write a 2×2 matrix as a product of elementary matrices; prove that if AB is invertible (A, B square) then A and B are invertible.
  - **C:** show that an upper triangular matrix is invertible ⇔ its diagonal entries are non-zero, and that the inverse is upper triangular (general n); find all right inverses of a 2×3 matrix.

## 05-rank.md — Row space, column space, null space and rank

- **Hook:** measure how much information a matrix carries. Three subspaces come attached to A.
- **Definitions:** `def-column-space`, `def-row-space`, `def-null-space` (as subspaces of F^m, Fⁿ, Fⁿ); `def-rank-matrix` = dim col(A); `def-nullity-matrix`.
- **Theorems:**
  - `thm-row-ops-row-space`: row operations preserve the row space and the column **relations**, but **not** the column space (warning, with a 2×2 example).
  - `thm-basis-column-space`: the pivot columns of **A** (not of the RREF) form a basis of col(A). This is sifting done by elimination; link to Ch 1 `thm-sift`.
  - `thm-basis-row-space`: the non-zero rows of the RREF form a basis of row(A).
  - `thm-basis-null-space`: the free-variable vectors form a basis of null(A); nullity = the number of free variables.
  - **Row rank = column rank** — `thm-row-rank-equals-column-rank`: both equal the number of pivots. Hence rank A = rank Aᵀ.
  - **Rank–nullity for matrices** — `thm-rank-nullity-matrix`: rank A + nullity A = n. Forward pointer to the Rank–Nullity Theorem for linear maps in Ch 3.
  - **Rouché–Capelli** — `thm-rouche-capelli`: Ax = b is consistent ⇔ rank A = rank [A | b]. When consistent, the solutions form a (n − rank A)-parameter family; over 𝔽_q there are exactly q^{n − rank A} solutions.
  - **Rank inequalities** — `thm-rank-product-inequality`: rank(AB) ≤ min(rank A, rank B), and equality when multiplying by an invertible matrix.
- **Computational toolkit** for Chapter 1 questions in Fⁿ (worked examples):
  - independence test (`exm-independence-by-rank`);
  - extending to a basis (append the standard basis and take the pivot columns: `exm-extend-basis-by-elimination`);
  - a basis of a sum U + W (`exm-sum-by-elimination`);
  - a basis of U ∩ W, by solving the null space of [U | −W] (`exm-intersection-by-elimination`).
- **Warnings:** the column space of the RREF is not the column space of A; rank depends only on A, not on the chosen echelon form.
- **Check.**
- **Exercises:**
  - **A.**
  - **B:** bases of the three spaces for a 3×5 matrix; decide independence and extend to a basis of ℝ⁴; compute dim(U ∩ W) and verify the dimension formula `thm-dimension-formula-subspace-dim`.
  - **C:** rank(A + B) ≤ rank A + rank B; an m×n matrix of rank 1 is xyᵀ with x, y non-zero; rank of the n×n matrix with entries i + j (it is 2 for n ≥ 2).

## 06-lu-factorization.md — LU and PLU factorizations

- **Hook:** solving Ax = b for many right-hand sides. Store the elimination as a matrix so we do not repeat it.
- **Definitions:** `def-lu-factorization` (L unit lower triangular, U upper triangular); `def-plu-factorization`.
- **Theorems:**
  - `thm-lu-exists-without-swaps`: if Gaussian elimination on A needs no row swaps, then A = LU, with L holding the multipliers. The proof needs products and inverses of unit lower triangular elementary matrices, which are unit lower triangular (`lem-unit-lower-triangular-closed`).
  - `thm-lu-unique`: for invertible A, the LU factorization (L unit lower) is unique.
  - `thm-plu-exists`: every square A has PA = LU for some permutation matrix P.
- **Solving** with forward and back substitution: worked example `exm-lu-solve`.
- **LDU and symmetric A:** A = LDLᵀ when A is symmetric and no swaps are needed — `thm-ldlt`. Forward pointer: Cholesky in Ch 12.
- **Non-example:** \( \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} \) has no LU factorization; show it directly.
- **Remark:** why swaps matter numerically (partial pivoting), as a forward pointer to Ch 23. Cost ≈ 2n³/3 operations.
- **Check.**
- **Exercises:**
  - **A.**
  - **B:** LU of a 3×3; solve two systems with the same LU; PLU of a matrix needing a swap.
  - **C:** show A has an LU factorization with invertible U ⇔ every leading principal submatrix is invertible (state as a challenge with hints, using the block view of elimination. **No determinants.**); LDLᵀ of a symmetric 3×3.

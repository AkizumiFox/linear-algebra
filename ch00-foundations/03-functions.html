0.3  Functions

Functions are the mathematical way to describe processes or transformations—rules that take an input and produce an output. In linear algebra, the central objects of study are linear maps (also called linear transformations), which are functions between vector spaces that respect the vector space structure. Understanding functions in general—especially their composition and inverses—is crucial because:

  • Matrix multiplication corresponds to composition of linear maps.
  • An invertible matrix corresponds to a bijective linear map.
  • Many proofs involve showing a linear map is injective, surjective, or bijective.

0.3.1. Definition and Basic Properties

Definition 0.3.1 (Function)

A function f from a set A to a set B, denoted f:A→B, is a rule that assigns to each element a∈A exactly one element f(a)∈B. The set A is called the domain and B is called the codomain.

Definition 0.3.2 (Injective, Surjective, Bijective)

Let f:A→B be a function.

  • f is injective (one-to-one) if f(a1)=f(a2) implies a1=a2.
  • f is surjective (onto) if for every b∈B, there exists a∈A such that f(a)=b.
  • f is bijective if it is both injective and surjective
Example (Injective, Surjective, and Bijective Functions)

Consider the following functions:

  1. f:R→R, f(x)=2x+1 is bijective.

    • Injective: If 2x1+1=2x2+1, then x1=x2.
    • Surjective: For any y∈R, we have f(y−12)=y.

  2. g:R→R, g(x)=x2 is neither injective nor surjective.

    • Not injective: g(1)=g(−1)=1, but 1≠−1.
    • Not surjective: There is no x∈R such that g(x)=−1.

  3. h:R→[0,∞), h(x)=x2 is surjective but not injective.

    • Not injective: h(1)=h(−1)=1.
    • Surjective: For any y≥0, we have h(y)=y.

  4. k:[0,∞)→R, k(x)=x2 is injective but not surjective.

    • Injective: If x12=x22 with x1,x2≥0, then x1=x2.
    • Not surjective: There is no x≥0 such that k(x)=−1.

0.3.2. Function Composition

When we apply one function after another, we obtain a composition. This concept is fundamental: matrix multiplication is precisely the composition of the corresponding linear maps.

Definition 0.3.3 (Function Composition)

Let f:A→B and g:B→C be functions. The composition of g with f, denoted g∘f, is the function g∘f:A→C defined by: (g∘f)(a)=g(f(a))for all a∈A We read g∘f as “g composed with f” or “g after f.”

Remark. The notation g∘f means “first apply f, then apply g.” The order matters and can be confusing—the function written on the right is applied first. This mirrors how matrix multiplication works: in ABx, we first multiply Bx, then multiply by A.

Example (Function Composition)

Let f:R→R be defined by f(x)=x2 and g:R→R by g(x)=x+1. We compute both compositions:

  • (g∘f)(x)=g(f(x))=g(x2)=x2+1
  • (f∘g)(x)=f(g(x))=f(x+1)=(x+1)2

Note that g∘f≠f∘g in general—composition is not commutative.

Theorem 0.3.1 (Associativity of Composition)

Let f:A→B, g:B→C, and h:C→D be functions. Then: (h∘g)∘f=h∘(g∘f) That is, function composition is associative.

Proof. For any a∈A: ((h∘g)∘f)(a)=(h∘g)(f(a))=h(g(f(a))) and (h∘(g∘f))(a)=h((g∘f)(a))=h(g(f(a))) Since both expressions equal h(g(f(a))) for all a∈A, the compositions are equal.

Theorem 0.3.2 (Composition Preserves Injectivity and Surjectivity)

Let f:A→B and g:B→C be functions.

  1. If f and g are both injective, then g∘f is injective.
  2. If f and g are both surjective, then g∘f is surjective.
  3. If f and g are both bijective, then g∘f is bijective.

Proof. We prove (1). Suppose f and g are injective and (g∘f)(a1)=(g∘f)(a2). Then g(f(a1))=g(f(a2)). Since g is injective, f(a1)=f(a2). Since f is injective, a1=a2. Thus g∘f is injective.

The proof of (2) and (3) are similar exercises.

0.3.3. Identity Function

Definition 0.3.4 (Identity Function)

For any set A, the identity function idA:A→A is defined by: idA(a)=afor all a∈A

Remark. The identity function satisfies f∘idA=f for any f:A→B, and idB∘f=f. It is the “do nothing” function. In matrix terms, the identity matrix In represents the identity function on Fn.

0.3.4. Inverse Functions

A bijective function can be “undone”—this leads to the concept of an inverse function. Understanding inverses is essential because invertible matrices are precisely those representing bijective linear maps.

Definition 0.3.5 (Inverse Function)

Let f:A→B be a function. A function g:B→A is called an inverse of f if: g∘f=idAandf∘g=idB If such a g exists, we say f is invertible and write g=f−1.

Theorem 0.3.3 (Bijective if and only if Invertible)

A function f:A→B is bijective if and only if it has an inverse f−1:B→A.

Moreover, if the inverse exists, it is unique.

Proof. (⇒) Suppose f is bijective. For each b∈B, since f is surjective, there exists some a∈A with f(a)=b. Since f is injective, this a is unique. Define g(b)=a. We verify that g is an inverse:

  • (g∘f)(a)=g(f(a))=a, so g∘f=idA.
  • (f∘g)(b)=f(g(b))=f(a)=b, so f∘g=idB.

Thus g=f−1 is an inverse of f.

(⇐) Suppose f has an inverse g. We show f is bijective:

  • Injective: If f(a1)=f(a2), then a1=g(f(a1))=g(f(a2))=a2.
  • Surjective: For any b∈B, we have f(g(b))=b, so b is in the image of f.

Uniqueness: If g and h are both inverses of f, then: g=g∘idB=g∘(f∘h)=(g∘f)∘h=idA∘h=h

Example (Inverse Functions)

The following examples illustrate inverse functions and when they do or do not exist:

  1. Let f:R→R be defined by f(x)=2x+3. This is bijective, and its inverse is f−1(y)=y−32.

    Verification: f(f−1(y))=2⋅y−32+3=y and f−1(f(x))=(2x+3)−32=x.

  2. Let g:R→R be defined by g(x)=x2. This is not bijective (not injective), so g−1 does not exist as a function R→R.

  3. Let h:[0,∞)→[0,∞) be defined by h(x)=x2. With restricted domain and codomain, h is bijective, and h−1(y)=y.

Theorem 0.3.4 (Inverse of a Composition)

If f:A→B and g:B→C are both bijective, then g∘f is bijective and: (g∘f)−1=f−1∘g−1

Proof. We verify the inverse property: (f−1∘g−1)∘(g∘f)=f−1∘(g−1∘g)∘f=f−1∘idB∘f=f−1∘f=idA Similarly, (g∘f)∘(f−1∘g−1)=idC.

Remark. Compare this to the matrix identity (AB)−1=B−1A−1 for invertible matrices. The reversal of order is the same phenomenon: to undo “first f, then g,” you must “first undo g, then undo f.”

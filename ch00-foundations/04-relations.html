0.4  Equivalence Relations

In mathematics, we often want to say that two objects are “the same” in some sense, even if they are not identical. For instance:

  • Two fractions 12 and 24 represent the same rational number.
  • Two matrices A and B are similar if B=P−1AP for some invertible P—they represent the same linear transformation in different bases.
  • Two vector spaces are isomorphic if there exists a bijective linear map between them—they have the same “structure.”

Each of these notions of “sameness” is captured by an equivalence relation. Understanding equivalence relations helps us recognize when different-looking objects are fundamentally alike.

0.4.1. Relations

Definition 0.4.1 (Relation)

A (binary) relation on a set A is a subset R⊆A×A. If (a,b)∈R, we write a∼b (or aRb) and say “a is related to b.”

Example (Examples of Relations)

Here are some common examples of relations:

  1. On Z, define a∼b if a≤b. This is the “less than or equal to” relation.

  2. On R, define a∼b if |a−b|<1. This says a and b are “close.”

  3. On the set of all people, define a∼b if a and b have the same birthday.

0.4.2. Equivalence Relations

Not all relations behave like “sameness.” An equivalence relation is one that satisfies three natural properties that any notion of sameness should have.

Definition 0.4.2 (Equivalence Relation)

A relation ∼ on a set A is an equivalence relation if it satisfies:

  1. Reflexivity: ∀a∈A:a∼a.

    (Every element is related to itself.)

  2. Symmetry: ∀a,b∈A:a∼b⇒b∼a.

    (If a is related to b, then b is related to a.)

  3. Transitivity: ∀a,b,c∈A:(a∼b∧b∼c)⇒a∼c.

    (If a is related to b and b is related to c, then a is related to c.)

Example (Examples of Equivalence Relations)

The following are all equivalence relations:

  1. Equality: On any set A, the relation a∼b⟺a=b is an equivalence relation (the finest one possible).

  2. Congruence modulo n: On Z, define a≡b(modn) if n∣(a−b).

    • Reflexive: n∣0, so a≡a.
    • Symmetric: If n∣(a−b), then n∣(b−a).
    • Transitive: If n∣(a−b) and n∣(b−c), then n∣((a−b)+(b−c))=(a−c).

  3. Same birthday: On the set of people, “a has the same birthday as b” is an equivalence relation.

  4. Same absolute value: On R, define a∼b⟺|a|=|b|. This is an equivalence relation.

Example (Non-Examples)

The following relations fail to be equivalence relations:

  1. On Z, the relation a≤b is not an equivalence relation:

    • Reflexive: Yes, a≤a.
    • Symmetric: No. 1≤2 but 2≰1.

  2. On R, the relation |a−b|<1 is not an equivalence relation:

    • Reflexive: Yes, |a−a|=0<1.
    • Symmetric: Yes.
    • Transitive: No. We have |0−0.6|<1 and |0.6−1.2|<1, but |0−1.2|=1.2≮1.

0.4.3. Equivalence Classes

An equivalence relation partitions a set into disjoint groups of “equivalent” elements. Each such group is called an equivalence class.

Definition 0.4.3 (Equivalence Class)

Let ∼ be an equivalence relation on A. The equivalence class of an element a∈A is the set of all elements equivalent to a: [a]={b∈A:b∼a} The element a is called a representative of the class [a].

Example (Examples of Equivalence Classes)

We illustrate equivalence classes with two examples:

  1. Congruence modulo 3: The equivalence classes of Z under ≡(mod3) are: [0]={…,−6,−3,0,3,6,9,…}[1]={…,−5,−2,1,4,7,10,…}[2]={…,−4,−1,2,5,8,11,…} Note that [0]=[3]=[6]=⋯ and [1]=[4]=[7]=⋯. Different representatives can name the same class.

  2. Same absolute value on R: The equivalence class of 2 is [2]={−2,2}. The equivalence class of 0 is [0]={0}.

Theorem 0.4.1 (Equivalence Classes Partition the Set)

Let ∼ be an equivalence relation on A. Then:

  1. Every element belongs to some equivalence class: a∈[a].
  2. Two equivalence classes are either equal or disjoint: [a]=[b] or [a]∩[b]=∅.
  3. The union of all equivalence classes is A.

In other words, the equivalence classes form a partition of A.

Proof.

  1. By reflexivity, a∼a, so a∈[a].

  2. Suppose [a]∩[b]≠∅, and let c∈[a]∩[b]. Then c∼a and c∼b. By symmetry, a∼c. By transitivity, a∼b.

Now we show [a]=[b]. Let x∈[a], so x∼a. Since a∼b, by transitivity x∼b, so x∈[b]. Thus [a]⊆[b]. By symmetry, [b]⊆[a], so [a]=[b].

  1. Follows from (1): every element a is in [a].
Definition 0.4.4 (Quotient Set)

Let ∼ be an equivalence relation on A. The quotient set (or quotient of A by ∼) is the set of all equivalence classes: A/∼={[a]:a∈A}

Example (Quotient Sets)

The following are examples of quotient sets:

  1. Z/≡3={[0],[1],[2]} has three elements. This is often written Z/3Z or Z3.

  2. The quotient of R by “same absolute value” is in bijection with [0,∞)—each equivalence class is determined by its absolute value.

0.4.4. Equivalence Relations in Linear Algebra

The following equivalence relations will appear throughout your study of linear algebra:

Example (Matrix Similarity)

On Mn(F), define A∼B if there exists an invertible matrix P∈Mn(F) such that B=P−1AP. This is called similarity.

  • Reflexive: A=I−1AI, so A∼A.
  • Symmetric: If B=P−1AP, then A=PBP−1=(P−1)−1B(P−1), so B∼A.
  • Transitive: If B=P−1AP and C=Q−1BQ, then C=Q−1P−1APQ=(PQ)−1A(PQ).

Similar matrices represent the same linear transformation in different bases. They share many properties: determinant, trace, eigenvalues, and characteristic polynomial.

Example (Row Equivalence)

Two matrices are row equivalent if one can be obtained from the other by a sequence of elementary row operations. This is an equivalence relation on Mm×n(F).

Remark. When you encounter a new equivalence relation, ask: “What properties do equivalent objects share?” For similarity, the answer includes eigenvalues and determinant. These shared properties are called invariants of the equivalence relation.

0.7  Matrices

Definition 0.7.1 (Matrix)

An m×n matrix over a field F is a rectangular array of elements from F arranged in m rows and n columns: A=[a11a12⋯a1na21a22⋯a2n⋮⋮⋱⋮am1am2⋯amn].

Remark. Mm×n(F) is the set of all matrices of size m×n and have entries in F. In the above definition, we can write A∈Mm×n(F).

Moreover, when m=n, we abbreviate Mm×n(F) to Mn(F).

Example (Matrices)

Here are some examples of matrices: [1234]∈M2(R),[10−1253]∈M2×3(R),[i1+i02−i]∈M2(C).

0.7.1. Special Matrices

Definition 0.7.2 (Zero Matrix)

The zero matrix O∈Mm×n(F) is the matrix with all entries equal to zero: O=[00⋯000⋯0⋮⋮⋱⋮00⋯0].

Definition 0.7.3 (Identity Matrix)

The identity matrix In∈Mn(F) is the n×n square matrix with 1s on the diagonal and 0s elsewhere: In=[10⋯001⋯0⋮⋮⋱⋮00⋯1]. When the size is clear from context, we simply write I.

Definition 0.7.4 (Transpose)

Let A=(aij)∈Mm×n(F). The transpose of A, denoted A⊤, is the n×m matrix obtained by swapping rows and columns: (A⊤)ij=aji. Visually, the rows of A become the columns of A⊤: [abcdef]⊤=[adbecf].

Definition 0.7.5 (Symmetric Matrix)

A square matrix A∈Mn(F) is symmetric if A=A⊤. This means it is symmetric across its main diagonal: A=[a11a12⋯a1na12a22⋯a2n⋮⋮⋱⋮a1na2n⋯ann].

Definition 0.7.6 (Diagonal Matrix)

A square matrix A∈Mn(F) is diagonal if all entries off the main diagonal are zero: A=[d10⋯00d2⋯0⋮⋮⋱⋮00⋯dn]. We often write A=diag(d1,d2,…,dn).

Definition 0.7.7 (Upper Triangular Matrix)

A square matrix A∈Mn(F) is upper triangular if all entries below the main diagonal are zero: A=[a11a12⋯a1n0a22⋯a2n⋮⋮⋱⋮00⋯ann].

Example (Zero and Identity Matrices)

O2×3=[000000],I2=[1001],I3=[100010001].

Example (Examples of Special Matrices)

Here are concrete examples illustrating the special types of matrices defined above:

  • Transpose: [123456]⊤=[142536].
  • Symmetric: [123245356] is symmetric since aij=aji.
  • Diagonal: diag(3,−1,0)=[3000−10000].
  • Upper Triangular: [123045006].

0.7.2. Matrix Addition

Definition 0.7.8 (Matrix Addition)

Let A=(aij) and B=(bij) be matrices in Mm×n(F). Their sum A+B is the matrix C=(cij)∈Mm×n(F) where: cij=aij+bij.

Definition 0.7.9 (Additive Inverse)

The additive inverse (or negation) of a matrix A=(aij)∈Mm×n(F) is the matrix −A=(−aij)∈Mm×n(F).

Example (Matrix Addition)

Let A=[1234] and B=[5678]. Then: A+B=[1234]+[5678]=[1+52+63+74+8]=[681012].

Theorem 0.7.1 (Properties of Matrix Addition)

Let A,B,C∈Mm×n(F). Then:

  1. A+B=B+A (Commutativity)
  2. (A+B)+C=A+(B+C) (Associativity)
  3. A+O=A (Additive identity)
  4. A+(−A)=O (Additive inverse)

Proof. We prove commutativity. Let A=(aij) and B=(bij). Then: (A+B)ij=aij+bij=bij+aij=(B+A)ij where the second equality uses commutativity of addition in the underlying field. Since this holds for all i,j, we have A+B=B+A.

The remaining properties follow similarly.

0.7.3. Matrix Multiplication

Definition 0.7.10 (Matrix Multiplication)

Let A=(aij)∈Mm×n(F) and B=(bjk)∈Mn×p(F). Their product AB is the matrix C=(cik)∈Mm×p(F) where: cik=∑j=1naijbjk In other words, the (i,k)-entry of AB is the dot product of the i-th row of A with the k-th column of B.

Example (Matrix Multiplication)

Let A=[1234]∈M2(R) and B=[5678]∈M2(R). We compute AB entry by entry: (AB)11=(1)(5)+(2)(7)=5+14=19(AB)12=(1)(6)+(2)(8)=6+16=22(AB)21=(3)(5)+(4)(7)=15+28=43(AB)22=(3)(6)+(4)(8)=18+32=50 Therefore: AB=[1234][5678]=[19224350]

Example (Matrix Multiplication with Different Dimensions)

Let A=[123456]∈M2×3(R) and B=[10−1]∈M3×1(R). The product AB∈M2×1(R): AB=[123456][10−1]=[(1)(1)+(2)(0)+(3)(−1)(4)(1)+(5)(0)+(6)(−1)]=[1+0−34+0−6]=[−2−2] Note that BA is not defined since the number of columns of B (which is 1) does not equal the number of rows of A (which is 2).

Theorem 0.7.2 (Properties of Matrix Multiplication)

Let A,B,C be matrices of compatible dimensions. Then:

  1. (AB)C=A(BC) (Associativity)
  2. A(B+C)=AB+AC (Left distributivity)
  3. (A+B)C=AC+BC (Right distributivity)
  4. AI=IA=A (Multiplicative identity)

Proof. We prove associativity. Let A be m×n, B be n×p, and C be p×q. For any entry (i,ℓ): ((AB)C)iℓ=∑k=1p(AB)ikckℓ=∑k=1p(∑j=1naijbjk)ckℓ=∑k=1p∑j=1naijbjkckℓ=∑j=1n∑k=1paijbjkckℓ=∑j=1naij(∑k=1pbjkckℓ)=∑j=1naij(BC)jℓ=(A(BC))iℓ

Remark. Matrix multiplication is not commutative in general. That is, AB≠BA even when both products are defined.

0.7.4. Scalar Multiplication

Definition 0.7.11 (Scalar Multiplication)

Let A=(aij)∈Mm×n(F) and c∈F be a scalar. The scalar multiple cA is the matrix in Mm×n(F) with entries (caij).

0.7.5. Trace of a Matrix

Definition 0.7.12 (Trace)

Let A=(aij)∈Mn(F) be a square matrix. The trace of A, denoted tr(A), is the sum of the entries on its main diagonal: tr(A)=∑i=1naii=a11+a22+⋯+ann.

Example (Trace)

Let A=[123456789]. Then tr(A)=1+5+9=15.

0.7.6. Properties of Transpose and Trace

Theorem 0.7.3 (Properties of Transpose)

Let A,B be matrices of compatible sizes and c∈F. Then:

  1. (A⊤)⊤=A
  2. (A+B)⊤=A⊤+B⊤
  3. (cA)⊤=cA⊤
  4. (AB)⊤=B⊤A⊤ (Reversal rule)

Proof. We prove the reversal rule (AB)⊤=B⊤A⊤. Let A∈Mm×n(F) and B∈Mn×p(F). ((AB)⊤)ij=(AB)ji=∑k=1najkbki Now consider B⊤A⊤. Its (i,j)-entry is: (B⊤A⊤)ij=∑k=1n(B⊤)ik(A⊤)kj=∑k=1nbkiajk=∑k=1najkbki Since the entries are equal for all i,j, we have (AB)⊤=B⊤A⊤.

Theorem 0.7.4 (Properties of Trace)

Let A,B∈Mn(F) and c∈F. Then:

  1. tr(A+B)=tr(A)+tr(B)
  2. tr(cA)=ctr(A)
  3. tr(A⊤)=tr(A)
  4. tr(AB)=tr(BA) (Cyclic property)

Proof. We prove tr(AB)=tr(BA). tr(AB)=∑i=1n(AB)ii=∑i=1n(∑j=1naijbji) Rearranging the summation: tr(AB)=∑j=1n∑i=1nbjiaij=∑j=1n(BA)jj=tr(BA).

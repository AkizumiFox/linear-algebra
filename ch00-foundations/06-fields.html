0.6  Fields

Definition 0.6.1 (Field)

A set F is called a field if we can define two binary operations addition +, and multiplication ⋅ +:F×F→F,⋅:F×F→F such that:

  • (F1) a+b=b+a
  • (F2) (a+b)+c=a+(b+c)
  • (F3) There exists 0∈F such that a+0=a.
  • (F4) For every a∈F, there exists −a∈F such that a+(−a)=0.
  • (F5) (a⋅b)⋅c=a⋅(b⋅c)
  • (F6) a⋅b=b⋅a
  • (F7) There exists 1∈F such that 1≠0 and a⋅1=a.
  • (F8) For every a∈F∖{0}, there exists a−1∈F such that a⋅a−1=1.
  • (F9) a⋅(b+c)=(a⋅b)+(a⋅c)

Remark. We can shorten “F is a field with operations + and ⋅” to “(F,+,⋅) is a field”. Moreover when the context of + and ⋅ is clear, we simply say “F is a field”, which we will do most of the time in this book.

Example (Examples of Fields)

The following sets are examples (and non-examples) of fields:

  1. R is a field.

  2. C is a field.

  3. Q={pq:p,q∈Z,q≠0} is a field.

  4. Z is not a field since (F8) fails.

  5. Mn(R) is not a field since (F6) fails.

Example (Finite Fields)

Let Fn be the finite field with n elements. Then (F2,+,⋅) is defined to be: F2={0,1},+01001110,⋅01000101.

Then one can verify that (F2,+,⋅) is a field.

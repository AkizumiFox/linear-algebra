3.4  The Algebra of Linear Maps

So far we have studied one linear map at a time: its kernel, its image, and the count that ties them together. But linear maps rarely come alone. The map p↦p+p′ is the identity plus differentiation, and rotating then projecting is one map followed by another. This section shows that linear maps can be added, scaled and composed, that these operations obey almost all the rules of arithmetic, and that an operator can be plugged into a polynomial just as a square matrix can.

3.4.1. Adding and scaling linear maps

Look at three maps on R[x]≤2 that have already appeared in this chapter or will soon: p↦p+p′,p↦3p′,p↦p′−2p. Each is built from two simpler maps, the identity id and differentiation D, by the recipe “apply both to p, then combine the outputs with the operations of the target space”. The first is “id+D”, the second “3D”, the third “D−2id”. Instead of checking linearity for each such combination separately, we would like to check it once for the recipe. The recipe itself deserves a name.

Linear maps into the same space can be added and scaled output by output, and the results are again linear maps.

Definition 3.4.1 (The space of linear maps)

Let V and W be vector spaces over the same field F. We write L(V,W) for the set of all linear maps V→W, and L(V):=L(V,V) for the set of linear operators on V (Definition 3.1.1). For S,T∈L(V,W) and c∈F, the sum S+T and the scalar multiple cT are the functions V→W defined by (S+T)(v):=Sv+Tv,(cT)(v):=c(Tv)for every v∈V.

As in Definition 3.1.1, we write Tv for T(v) when no brackets are needed. In words: to evaluate S+T at v, evaluate both maps at v and add the results in W; to evaluate cT, evaluate T and scale the result in W. The operations of V play no role in the definition. That is why S and T must have the same codomain: the sum Sv+Tv has to be computed in one space. Both maps must also be defined on the same V.

We have used these operations before without naming them: the operations on FX in Example (The Standard Vector Spaces) (d) are defined by the same pointwise recipe, with values added in F instead of W.

It turns out that the recipe never leaves the world of linear maps, and that L(V,W) is itself a vector space. This is the first sign that maps between vector spaces are as good as vectors.

Theorem 3.4.1 (L(V,W) Is a Vector Space)

Let V and W be vector spaces over F. If S,T∈L(V,W) and c∈F, then S+T and cT are linear. With the operations of Definition 3.4.1, L(V,W) is a vector space over F. Its zero vector is the zero map v↦0W, and the negative of T is (−1)T:v↦−Tv.

Idea. There are two layers. The set WV of all functions V→W, with the pointwise operations, is a vector space, for the same reason FX is: each axiom is checked one input at a time, where it becomes an axiom of W. Then L(V,W) sits inside WV, so the Subspace Test finishes the job, and its three conditions are exactly “the zero map is linear”, “a sum of linear maps is linear” and “a multiple of a linear map is linear”.

Proof. Let WV be the set of all functions V→W, with the operations of Definition 3.4.1 applied to arbitrary functions. The verification in Example (The Standard Vector Spaces) (d) goes through word for word with W in place of F: two functions V→W are equal when they agree at every v∈V (Definition 0.4.1), and at each v every axiom for WV becomes the same axiom in W, with zero function v↦0W and negative v↦−f(v). Hence WV is a vector space over F, and L(V,W)⊆WV. We apply Theorem 1.2.1.

  1. The zero map is linear: 0W=0W+0W and 0W=c0W by Theorem 1.1.6. So 0∈L(V,W).

  2. Let S,T∈L(V,W), u,v∈V and a∈F. By the definition of S+T, the linearity of S and T, and the axioms of W, (S+T)(u+v)=Su+Sv+Tu+Tv=(S+T)u+(S+T)v, (S+T)(av)=aSv+aTv=a(Sv+Tv)=a(S+T)v. So S+T∈L(V,W).

  3. Let c∈F and T∈L(V,W). Then (cT)(u+v)=c(Tu+Tv)=(cT)u+(cT)v, and (cT)(av)=c(aTv)=(ca)Tv=(ac)Tv=a(cT)v, using the axioms of W and commutativity of multiplication in F. So cT∈L(V,W).

By Theorem 1.2.1, L(V,W) is a subspace of WV, hence a vector space over F with the same zero and negatives. The negative of T in WV is v↦−Tv=(−1)Tv, by Theorem 1.1.7. This proves the theorem.

The step that used commutativity of F is worth a second look: cT is linear because c can be moved past the scalar a. This is one place where “F is a field” is used silently.

Example (Sums of Matrix Maps and Other First Examples)

For A∈Mm×n(F), write TA:Fn→Fm, x↦Ax, for the matrix map of Example (Multiplication by a Matrix).

  • (a) Show that TA+TB=TA+B and cTA=TcA for A,B∈Mm×n(F) and c∈F.
  • (b) Describe L(V,W) when V={0}, and when W={0}.
  • (c) On R[x]≤2, write T(p)=p′−2p in terms of id and D, and compute T(1+x2).

Solution.

  • (a) Let x∈Fn. By Definition 3.4.1 and distributivity (Theorem 0.9.4), (TA+TB)(x)=Ax+Bx=(A+B)x=TA+B(x),(cTA)(x)=c(Ax)=(cA)x=TcA(x). The maps agree at every x, so they are equal. So adding and scaling matrix maps is adding and scaling matrices.

  • (b) If V={0}, a linear map must send 0 to 0W, so the zero map is the only element: L({0},W)={0}. If W={0}, every function V→{0} is the zero map, and it is linear, so again L(V,{0})={0}. These degenerate cases matter because formulas like “dim⁡L(V,W)=dim⁡V⋅dim⁡W”, which we prove later in this chapter, must give 0 here, and they do.

  • (c) T=D−2id, which is linear by Theorem 3.4.1. With p=1+x2, p′=2x, so T(p)=2x−2−2x2.

Here is a non-example by minimal change. Keep D on R[x]≤2, but replace id by the evaluation map E(p)=p(0)∈R. Both maps are linear and both are defined on R[x]≤2. But D lands in R[x]≤2 and E lands in R, so D+E would require adding a polynomial to a number. The clause that fails is “S,T∈L(V,W)” with the same W: the sum is not defined.

3.4.2. Composition

Addition makes L(V,W) a vector space, but the operation that really matters for maps is doing one after another. For functions, Chapter 0 wrote this as S∘T (Definition 0.4.4). For linear maps we drop the circle.

Remark. Notation. For T∈L(U,V) and S∈L(V,W), we write ST:=S∘T:U→W, so (ST)u=S(Tu). The map written on the right acts first. For an operator T∈L(V), T2=TT means “apply T twice”, never “square the output”.

Is ST linear, and how does composition interact with the sum? It turns out that composition behaves like a multiplication: associative, with identities, and distributive over addition on both sides.

Theorem 3.4.2 (Composition of Linear Maps)

Let U,V,W,X be vector spaces over F.

  • (a) (Linearity) If T∈L(U,V) and S∈L(V,W), then ST∈L(U,W).
  • (b) (Associativity) If T∈L(U,V), S∈L(V,W) and R∈L(W,X), then R(ST)=(RS)T.
  • (c) (Identities) If T∈L(U,V), then TidU=T=idVT.
  • (d) (Distributivity) If T,T1,T2∈L(U,V), S,S1,S2∈L(V,W) and c∈F, then (S1+S2)T=S1T+S2T,S(T1+T2)=ST1+ST2,(cS)T=c(ST)=S(cT).

Idea. Parts (b) and (c) hold for all functions, so there is nothing new to do. Part (a) is a two-line check. The interesting point is in (d): the three identities are not equally cheap. In (S1+S2)T the map T acts first and the sum is taken afterwards, so the identity is just the definition of the sum. In S(T1+T2) the sum is taken before S acts, and pulling it out of S needs S to be linear. So we should watch where the linearity of the left factor is spent.

Proof.

  • (a) Let u,u′∈U and a∈F. Since T and then S are linear, ST(u+u′)=S(Tu+Tu′)=STu+STu′,ST(au)=S(aTu)=aSTu.

  • (b) and (c) hold for arbitrary functions, by Theorem 0.4.2 and the observation after Definition 0.4.5.

  • (c) Each side is a function U→W, so we compare values at u∈U. By Definition 3.4.1, (S1+S2)Tu=S1(Tu)+S2(Tu)=(S1T+S2T)u, with no linearity used. Next, since S is linear, S(T1+T2)u=S(T1u+T2u)=ST1u+ST2u=(ST1+ST2)u. Finally (cS)(Tu)=c(STu) by definition, and S(cTu)=c(STu) because S is linear. This proves the theorem.

In short, L(V) carries a vector space structure and a multiplication (composition) that is associative, has the unit idV, distributes over addition, and lets scalars move freely through products. A vector space with such a multiplication is called an algebra over F; Mn(F) is the other algebra we know (Theorem 0.9.4). The two will turn out to be the same algebra in disguise when we write operators as matrices later in this chapter.

Example (Rotate, Then Project)

Let R:R2→R2 be the rotation by 90∘ counterclockwise, R(x,y)=(−y,x), and let P:R2→R2, P(x,y)=(x,0), be the projection onto the x-axis. Compute PR and RP.

Solution. In PR the rotation acts first: PR(x,y)=P(−y,x)=(−y,0),RP(x,y)=R(x,0)=(0,x). At (1,0): PR(1,0)=(0,0), while RP(1,0)=(0,1). So PR≠RP. Geometrically, PR rotates e1 onto the y-axis and then squashes it to 0; RP leaves e1 alone under the projection and then rotates it to e2. In matrix form, P=TA and R=TB with A=(1000) and B=(0−110), and indeed AB=(0−100)≠(0010)=BA.

Warning. Composition is not commutative, and the order is read right to left. In Example (Rotate, Then Project), PR≠RP. It can be worse: for T∈L(R2,R3) and S∈L(R3,R2), both ST∈L(R2) and TS∈L(R3) are defined, but they live on different spaces, so they cannot even be compared. And for T∈L(R2,R3), S∈L(R3,R4), ST is defined but TS is not. The thing you do first goes on the right.

Quick check. Let T:R3→R2 and S:R2→R4 be linear. Which of ST and TS is defined, and between which spaces does it go?

Solution. ST=S∘T first applies T:R3→R2, then S:R2→R4, so ST∈L(R3,R4). TS would apply S first, landing in R4, where T is not defined; so TS is not defined.

Because of the missing commutativity, school identities about products must be rechecked. By distributivity (Theorem 3.4.2 (d)), (S+T)2=(S+T)(S+T)=S2+ST+TS+T2, which equals S2+2ST+T2 only if ST=TS. With P and R as above, PR+RP:(x,y)↦(−y,x), while 2PR:(x,y)↦(−2y,0); so (P+R)2≠P2+2PR+R2. This is the operator version of the matrix warning in Chapter 0, §9.

3.4.3. Operators, powers and polynomials

Composition of operators on one space V never leaves L(V), so we may compose an operator with itself as often as we like. Repeated composition leads to powers, and combinations of powers to polynomials, exactly as for square matrices (Definition 0.9.14).

Definition 3.4.2 (Powers and Polynomials of an Operator)

Let V be a vector space over F and T∈L(V). The powers of T are defined recursively by T0:=idV,Tk+1:=TkT(k∈N). For p=a0+a1x+⋯+aNxN∈F[x], the operator p(T)∈L(V) is p(T):=a0idV+a1T+a2T2+⋯+aNTN.

In words: Tk applies T exactly k times, and T0 does nothing. In p(T), the constant term becomes a0idV, because an operator cannot be added to a scalar. Each Tk is linear by Theorem 3.4.2 (a) and induction, and p(T) is linear by Theorem 3.4.1. As for matrices, p(T) does not depend on how many zero coefficients we write, since 0⋅Tk is the zero map.

Plugging in an operator respects sums and products of polynomials, just as plugging in a matrix does.

Theorem 3.4.3 (Polynomials in One Operator)

Let T∈L(V) and p,q∈F[x]. Then:

  • (a) TjTk=Tj+k for all j,k∈N;
  • (b) (p+q)(T)=p(T)+q(T) and (pq)(T)=p(T)q(T);
  • (c) p(T)q(T)=q(T)p(T).

Idea. The proof of Theorem 0.9.9 used four matrix rules: associativity, identity, distributivity and “scalars move through products”. Theorem 3.4.2 supplies exactly these four rules for operators. So the old proof transfers line by line. Part (c) is the surprise: T need not commute with other operators, but it commutes with every polynomial in itself.

Proof.

  • (a) Fix j and use induction on k (Theorem 0.2.7). For k=0, TjT0=TjidV=Tj by Theorem 3.4.2 (c). If TjTk=Tj+k, then by Definition 3.4.2 and associativity (Theorem 3.4.2 (b)), TjTk+1=Tj(TkT)=(TjTk)T=Tj+kT=Tj+k+1.

  • (b) Let p=∑i=0maixi and q=∑j=0lbjxj. The statement for sums holds because (ai+bi)Ti=aiTi+biTi in the vector space L(V) (Theorem 3.4.1). For products, the coefficient of xk in pq is ∑i+j=kaibj (Definition 0.8.2), so (pq)(T)=∑k(∑i+j=kaibj)Tk=∑i=0m∑j=0l(aibj)TiTj=(∑i=0maiTi)(∑j=0lbjTj)=p(T)q(T), where the second equality uses (a), and the third uses both distributive laws and (aiTi)(bjTj)=(aibj)TiTj, all from Theorem 3.4.2 (d).

  • (c) Since pq=qp in F[x] (Theorem 0.8.1), part (b) gives p(T)q(T)=(pq)(T)=(qp)(T)=q(T)p(T). This proves the theorem.

In practice, (b) says that a factorization of p is a factorization of p(T): for instance T2−3T+2idV=(T−idV)(T−2idV)=(T−2idV)(T−idV).

Example (Differentiation Is Nilpotent)

Let n≥0 and let D∈L(F[x]≤n) be (formal) differentiation (Example (Differentiation)), D(a0+a1x+⋯+anxn)=a1+2a2x+⋯+nanxn−1, where kak means ak added to itself k times. Show that Dn+1=0. Show also that Dn≠0 when F=R.

Solution. For 0≤k≤n, D(xk)=kxk−1 if k≥1 and D(1)=0. So D sends each xk to a scalar multiple of xk−1, or to 0 when k=0. Applying this k+1 times, Dk+1(xk) is a scalar multiple of D(1)=0, so Dk+1(xk)=0. Since k≤n, also Dn+1(xk)=Dn−k(Dk+1(xk))=Dn−k(0)=0, by Theorem 3.4.3 (a).

Now let p=a0+a1x+⋯+anxn. Since Dn+1 is linear, Theorem 3.1.4 gives Dn+1(p)=a0Dn+1(1)+a1Dn+1(x)+⋯+anDn+1(xn)=0. Hence Dn+1=0.

Over R, Dn(xn)=n(n−1)⋯1=n!≠0, so Dn≠0. Over F2 with n=2, however, D(x2)=2x=0, and D2=0 already; the field matters for the exact power, but never for Dn+1=0.

An operator T with Tk=0 for some k≥1 is called nilpotent. The example shows that a non-zero operator can have a power equal to zero, just as the matrix (0100) can. Differentiation is the model nilpotent operator, and it returns when we study canonical forms.

Example (Operators That Satisfy a Polynomial)

With P and R as in Example (Rotate, Then Project), find non-zero polynomials p and q with p(P)=0 and q(R)=0. Also, for an arbitrary p∈F[x], compute p(idV) and p(Z), where Z∈L(V) is the zero operator.

Solution. For the projection, P2(x,y)=P(x,0)=(x,0)=P(x,y), so P2=P and p=x2−x satisfies p(P)=P2−P=0. By Theorem 3.4.3 (b), this says P(P−id)=0: whatever P−id produces is killed by P, and indeed (P−id)(x,y)=(0,−y) lies on the y-axis.

For the rotation, R2(x,y)=R(−y,x)=(−x,−y), so R2=−id, and q=x2+1 satisfies q(R)=R2+id=0. Rotating twice by 90∘ is rotating by 180∘. Since q has no real roots, q has no real linear factor, so the trick “factor q, then factor q(R)” gives nothing over R.

For p=a0+a1x+⋯+aNxN: every power of idV is idV, so p(idV)=(a0+a1+⋯+aN)idV=p(1)idV. Every power Zk with k≥1 is the zero map, but Z0=idV, so p(Z)=a0idV, the scalar p(0) times idV. The second computation is the reason for the convention T0=idV: with it, “the constant term” of p(T) is what survives when T is the zero operator.

Warning. The constant term is a0idV, not a0. Writing “P2−P+3” for an operator is a type error: P2−P is a map and 3 is a number. For p=x2−x+3, p(P)=P2−P+3id, which is 3id since P2=P. Forgetting the id leads to “p(P)=3”, which is not an operator at all.

Quick check. With P the projection above, compute p(P) for p=x3−2x+1.

Solution. Since P2=P, also P3=P2P=PP=P. So p(P)=P3−2P+id=P−2P+id=id−P, which is the map (x,y)↦(0,y): the projection onto the y-axis.

Polynomial relations such as P2=P, R2=−id and Dn+1=0 carry real information about an operator. In the next section we use one to write down an inverse without solving any equations, and later in the book the polynomials that kill an operator lead to the minimal polynomial and to canonical forms.

3.4.4. Exercises

A. Check your understanding

Exercise (A1)
  • (a) For S,T∈L(V,W) and c∈F, define S+T and cT. Why must S and T have the same codomain?
  • (b) True or false: for all S,T∈L(V), ST=TS. Justify your answer.
  • (c) Let T∈L(R5,R2) and S∈L(R2,R5). Which of ST, TS are defined, and in which spaces do they lie?
  • (d) For T∈L(V) and p=4 (a constant polynomial), what is p(T)?
  • (e) True or false: for all S,T∈L(V), (S+T)2=S2+2ST+T2. Justify your answer.

Solution.

  • (a) (S+T)(v)=Sv+Tv and (cT)(v)=cTv for every v∈V (Definition 3.4.1). The sum Sv+Tv must be computed in a single vector space, so both values must lie in the same W.

  • (b) False. In Example (Rotate, Then Project), PR(1,0)=(0,0) but RP(1,0)=(0,1).

  • (c) Both are defined. ST applies T first: ST∈L(R5). TS applies S first: TS∈L(R2).

  • (d) p(T)=4idV, by Definition 3.4.2.

  • (e) False. By Theorem 3.4.2 (d), (S+T)2=S2+ST+TS+T2, which differs from S2+2ST+T2 by TS−ST. With S=P, T=R of Example (Rotate, Then Project), RP−PR:(x,y)↦(y,x) is not the zero map, so the identity fails.

B. Practice

Exercise (B1: Computing compositions)

Let S,T∈L(R2) be given by S(x,y)=(x+y,y) and T(x,y)=(y,x).

  • (a) Compute ST, TS and 2S−T.
  • (b) Compute S2 and Sk for every k∈N.
  • (c) Hence show that (S−id)2=0.

Solution.

  • (a) Applying the right-hand map first, ST(x,y)=S(y,x)=(x+y,x),TS(x,y)=T(x+y,y)=(y,x+y). So ST≠TS; for instance ST(1,0)=(1,1) and TS(1,0)=(0,1). By Definition 3.4.1, (2S−T)(x,y)=(2x+2y,2y)−(y,x)=(2x+y,2y−x).

  • (b) S2(x,y)=S(x+y,y)=(x+2y,y). We claim Sk(x,y)=(x+ky,y) for all k∈N, by induction on k. For k=0, S0=id sends (x,y) to (x+0y,y). If the claim holds for k, then Sk+1(x,y)=Sk(S(x,y))=Sk(x+y,y)=(x+y+ky,y)=(x+(k+1)y,y), where the first equality is Definition 3.4.2, Sk+1=SkS.

  • (c) (S−id)(x,y)=(y,0), so (S−id)2(x,y)=(S−id)(y,0)=(0,0). Hence (S−id)2=0, that is, S−id is nilpotent. Expanding with Theorem 3.4.3 (b), S2−2S+id=0, which matches (b): (x+2y,y)−2(x+y,y)+(x,y)=(0,0).

Exercise (B2: Operators that preserve a subspace)

Let U be a subspace of V, and let AU:={T∈L(V):Tu∈U for every u∈U}. Prove that AU is a subspace of L(V), that idV∈AU, and that ST∈AU whenever S,T∈AU.

Solution. We use Theorem 1.2.1 in the vector space L(V) (Theorem 3.4.1).

  1. The zero map sends every u∈U to 0, and 0∈U because U is a subspace. So 0∈AU.

  2. Let S,T∈AU and u∈U. Then Su∈U and Tu∈U, so (S+T)u=Su+Tu∈U, since U is closed under addition. Therefore S+T∈AU.

  3. Let c∈F and T∈AU. For u∈U, (cT)u=cTu∈U, since U is closed under scalar multiplication. Therefore cT∈AU.

Hence AU is a subspace of L(V). Next, idVu=u∈U for every u∈U, so idV∈AU. Finally let S,T∈AU and u∈U. Then Tu∈U, and applying the hypothesis on S to the vector Tu∈U gives STu=S(Tu)∈U. This shows ST∈AU.

Exercise (B3: A polynomial that kills D)

Let D∈L(R[x]≤2) be differentiation.

  • (a) Find a non-zero polynomial p with p(D)=0.
  • (b) Show that no non-zero polynomial q of degree at most 2 satisfies q(D)=0.
  • (c) Hence, or otherwise, compute (id+D)3 as a combination of id,D,D2, and evaluate (id+D)3(x2).

Solution.

  • (a) By Example (Differentiation Is Nilpotent) with n=2, D3=0. So p=x3 works.

  • (b) Let q=a+bx+cx2 with q(D)=aid+bD+cD2=0. Applying this operator to x2, with D(x2)=2x and D2(x2)=2, 0=ax2+2bx+2c. A polynomial is zero exactly when all its coefficients are, so a=0, 2b=0 and 2c=0. Hence a=b=c=0 and q=0.

  • (c) The operator id+D is q(D) for q=1+x. Applying the product rule of Theorem 3.4.3 (b) twice, (id+D)3=q(D)q(D)q(D)=(q3)(D), and q3=1+3x+3x2+x3. So (id+D)3=id+3D+3D2+D3=id+3D+3D2, using D3=0 from (a). Therefore (id+D)3(x2)=x2+3⋅2x+3⋅2=x2+6x+6.

C. Going deeper

Exercise (C1: The Heisenberg relation)

Let F be a field, let D∈L(F[x]) be formal differentiation, D(∑kakxk)=∑k≥1kakxk−1 (Example (Differentiation)), and let S∈L(F[x]) be multiplication by x, S(p)=xp (the map M of Example (Multiplication by x)).

  • (a) Prove that DS−SD=id.
  • (b) Let T∈L(Fn,Fm). Prove that T=TA, where A∈Mm×n(F) is the matrix with columns Te1,…,Ten.
  • (c) Now suppose that F has characteristic 0 (Definition 0.7.2), and let n≥1. Deduce that there are no operators D′,S′∈L(Fn) with D′S′−S′D′=id.
  • (d) Show that the assumption on the characteristic in (c) cannot be dropped.

Hint: for (c), use (b) and consider traces.

Solution.

  • (a) Both sides are linear (Theorem 3.4.1, Theorem 3.4.2). We first compare them on xk, k∈N. We have DS(xk)=D(xk+1)=(k+1)xk. If k≥1, SD(xk)=x⋅kxk−1=kxk; if k=0, SD(1)=x⋅0=0=0⋅x0. In both cases (DS−SD)(xk)=(k+1)xk−kxk=xk=id(xk). Every p∈F[x] is a finite combination p=∑kakxk, so by Theorem 3.1.4, (DS−SD)(p)=∑kak(DS−SD)(xk)=∑kakxk=p. Hence DS−SD=id.

  • (b) Let x=(x1,…,xn)=x1e1+⋯+xnen∈Fn. By Theorem 3.1.4 and Theorem 0.9.3, Tx=x1Te1+⋯+xnTen=Ax=TA(x). Since x was arbitrary, T=TA.

  • (c) Suppose, for a contradiction, that D′,S′∈L(Fn) satisfy D′S′−S′D′=id. By (b), D′=TA and S′=TB for some A,B∈Mn(F), and id=TIn. By associativity of matrix multiplication, TATB(x)=A(Bx)=(AB)x, so TATB=TAB, and similarly TBTA=TBA. With Example (Sums of Matrix Maps and Other First Examples) (a), TAB−BA=TATB−TBTA=id=TIn. Evaluating at ej gives equal j-th columns (Theorem 0.9.3), so AB−BA=In. Taking traces and using Theorem 0.9.6, n⋅1=trIn=tr(AB)−tr(BA)=0. Since n≥1 and F has characteristic 0, n⋅1≠0 by Definition 0.7.2. This is a contradiction, so no such D′,S′ exist. In words: over Q, R, C or any field of characteristic 0, the relation DS−SD=id of (a) has no analogue on Fn, n≥1. Since every n-dimensional space is isomorphic to Fn, as we show in the next section, the same holds on every non-zero finite-dimensional space. (On the zero space id=0, so the relation holds trivially there; that is why n≥1.)

  • (d) Over F2 (characteristic 2), take A=(0010) and B=(0100) as in Exercise (C1: AB−BA=I is impossible, or is it?). There AB−BA=(−1001)=I2, because −1=1 in F2. By the computation in (c), D′=TA and S′=TB satisfy D′S′−S′D′=TAB−BA=id on F22. So the conclusion of (c) fails without the characteristic assumption; the proof breaks exactly at n⋅1≠0, since 2⋅1=0 in F2.

Exercise (C2: Commuting nilpotent operators)

Let S,T∈L(V).

  • (a) Suppose ST=TS. Prove that (S+T)n=∑k=0n(nk)SkTn−k for every n∈N, where (nk)SkTn−k means SkTn−k added to itself (nk) times.
  • (b) Deduce that if ST=TS, Sa=0 and Tb=0 for some a,b≥1, then (S+T)a+b−1=0.
  • (c) Show that (b) fails without ST=TS: give nilpotent S,T∈L(R2) such that S+T is not nilpotent.

Hint: for (c), try maps that send one standard basis vector to the other and the other to 0.

Solution.

  • (a) First, TjS=STj for all j∈N, by induction on j: it holds for j=0, and if TjS=STj, then Tj+1S=Tj(TS)=Tj(ST)=(TjS)T=(STj)T=STj+1, using associativity (Theorem 3.4.2 (b)) and Theorem 3.4.3 (a) in the form Tj+1=TjT.

    Now induct on n. For n=0 both sides are idV. Suppose the formula holds for n. By Theorem 3.4.2 (d), (S+T)n+1=(S+T)n(S+T)=∑k=0n(nk)SkTn−kS+∑k=0n(nk)SkTn−k+1. By the first paragraph, SkTn−kS=Sk(Tn−kS)=SkSTn−k=Sk+1Tn−k. Shifting the index in the first sum, the coefficient of SkTn+1−k becomes (nk−1)+(nk)=(n+1k) (Pascal’s rule, with (n−1)=(nn+1)=0). This is the formula for n+1.

  • (b) By (a) with n=a+b−1, (S+T)a+b−1 is a sum of multiples of SkTa+b−1−k, 0≤k≤a+b−1. If k≥a, then Sk=Sk−aSa=0 by Theorem 3.4.3 (a), so the term is 0 by Theorem 3.4.2 (d). If k≤a−1, then a+b−1−k≥b, so Ta+b−1−k=0 likewise. Every term vanishes, so (S+T)a+b−1=0.

  • (c) Let S(x,y)=(y,0) and T(x,y)=(0,x). Then S2(x,y)=S(y,0)=(0,0) and T2(x,y)=T(0,x)=(0,0), so both are nilpotent. But (S+T)(x,y)=(y,x), so (S+T)2(x,y)=(x,y), that is, (S+T)2=id. Then (S+T)2k=id≠0 and (S+T)2k+1=S+T≠0 for every k, so S+T is not nilpotent. Here ST(x,y)=(x,0)≠(0,y)=TS(x,y), so the hypothesis of (b) indeed fails.

3.2  Kernel and Image

3.2.1. Definition

Definition 3.2.1 (Kernel)

Let f:V→W be a linear transformation. Define the kernel of f by ker(f):={v∈V:f(v)=0W}.

i.e. The kernel contains everything in the domain that becomes the zero vector under f.

Definition 3.2.2 (Image)

Let f:V→W be a linear transformation. Define the image of f by im(f):={w∈W:w=f(v) for some v∈V}.

i.e. The image contains all the possible outputs of the function f.

Remark. The kernel is also known as the nullspace, which you might be familiar from Gilbert Strang’s book. And the image is also called the range. Also, we sometimes denote the image as f(V).

3.2.2. Examples

Example (Differentiation)

Let D:R[x]≤3→R[x]≤2 be defined by D(f(x))=f′(x). Find the kernel and image of D.

Solution. Kernel: We seek all polynomials f(x)∈R[x]≤3 such that D(f(x))=f′(x)=0.

A polynomial has derivative zero if and only if it is a constant. Thus: ker(D)={c:c∈R}=span{1}. So dim⁡(ker(D))=1.

Image: We need to determine which polynomials in R[x]≤2 can be obtained as derivatives.

Let f(x)=a0+a1x+a2x2+a3x3∈R[x]≤3. Then: D(f(x))=f′(x)=a1+2a2x+3a3x2. As a1,a2,a3 range over all real numbers, we can obtain any polynomial of degree at most 2. Therefore: im(D)=R[x]≤2. So dim⁡(im(D))=3.

Note that dim⁡(ker(D))+dim⁡(im(D))=1+3=4=dim⁡(R[x]≤3).

Example (Trace)

Let tr:M2(R)→R be defined by tr(A)=a11+a22. Find the kernel and image of tr.

Solution. Kernel: We seek all matrices A∈M2(R) such that tr(A)=0.

Let A=[abcd]. Then tr(A)=a+d=0, which means d=−a.

So the kernel consists of all matrices of the form: A=[abc−a]=a[100−1]+b[0100]+c[0010]. Therefore: ker(tr)=span{[100−1],[0100],[0010]}. So dim⁡(ker(tr))=3.

Image: For any r∈R, we can find a matrix with trace r, for example [r000].

Therefore: im(tr)=R. So dim⁡(im(tr))=1.

Note that dim⁡(ker(tr))+dim⁡(im(tr))=3+1=4=dim⁡(M2(R)).

3.2.3. Basic Theorems

Theorem 3.2.1 (Properties of Kernel)

Let f:V→W be a linear transformation. Then:

  1. ker(f) is a subspace of V;

  2. f is injective iff ker(f)={0V}.

Proof.

    • Non-emptiness: As f is linear, f(0V)=0W, therefore 0V∈ker(f).
    • Closure under addition: Let v1,v2∈ker(f), it implies that f(v1)=0W and f(v2)=0W. We have f(v1+v2)=f(v1)+f(v2)=0W+0W=0W. Therefore v1+v2∈ker(f).
    • Closure under scalar multiplication: Let v∈ker(f), it implies that f(v)=0W. We have f(λv)=λf(v)=λ0W=0W. Therefore λv∈ker(f).
    • (⇒) Suppose f is injective. Let v∈ker(f), we have f(v)=0W=f(0V)(linearity) By having f(v)=f(0V) and f is injective, it implies that v=0V, so ker(f)={0V}.
    • (⇐) Suppose ker(f)={0V}, and we consider f(v)=f(w). Reordering the terms we get f(v)−f(w)=0W, and since f is linear we have f(v−w)=0W. Therefore v−w∈ker(f)={0V}, implying that v−w=0V, hence v=w. So f is injective.
Theorem 3.2.2 (Properties of Image)

Let f:V→W be a linear transformation. Then:

  1. im(f) is a subspace of W;

  2. f is surjective iff im(f)=W.

Proof.

    • Non-emptiness: Since f is linear, 0W=f(0V), therefore 0W∈im(f).
    • Closure under addition: Let w1,w2∈im(f). So w1=f(v1), and w2=f(v2) for some v1,v2∈V. Notice that w1+w2=f(v1)+f(v2)=f(v1+v2). Therefore w1+w2∈im(f).
    • Closure under scalar multiplication: Let w∈im(f). So w=f(v) for some v∈V. Notice that λw=λf(v)=f(λv). Therefore λw∈im(f).
  2. f is surjective ⇔ ∀w∈W, we have w∈f(v) for some v∈V, that is equivalent to say W⊆im(f), and by the first condition we know that im(f)⊆W is always true. Hence we have f is surjective ⇔ W=im(f).
